## 9. 已知坑（避免重复踩）

- 本会话 `ops_bash` 是 **Windows MSYS bash**（`pwd` 为 `//wsl.localhost/...`）；Linux 命令必须走 `wsl.exe -d Ubuntu-22.04 -e bash -c '...'`，或把 .sh/.py 写到磁盘再用 WSL 执行。复杂引号/管道经 MSYS 会被拆坏（`$VAR`、`$(...)` 会被本机展开）。
- `tools.write`/`tools.edit` 对 UNC 路径偶发 `GetFileSecurityW EIO` → 改用 `printf '%s' <base64> | base64 -d > file` 或写 python 补丁脚本再跑。
- `run_code` 单次默认 120 s 上限；长任务用 `run_in_background + job_output`，或在 `ops_bash` 指定 `timeoutMs`（≤600 s）且 run_code 也要给足 `timeoutMs`。
- 后台 bash 运行期间再发 `ops_bash` 可能触发 dsh-ops 链接竞争（`EXECUTOR_UNAVAILABLE ... link 'awk.exe'`），等 job 结束自动恢复。
- `torch.cuda.max_memory_allocated()` 对 mujoco-warp 无效（自带 mempool），显存必须用 `nvidia-smi` 采样。
- 相机跟随不能用 `sim.data.qpos`（每个 world 的相对坐标），要用 `entity.data.root_link_pos_w`（世界系）。
- mjlab 默认只渲染 3 个 env（`max_extra_envs=2`），多 env 录像前必须调大。
