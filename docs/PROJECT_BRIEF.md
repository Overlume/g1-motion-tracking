# PROJECT_BRIEF

> **历史快照**：本文是 2026-11-11 读入的原始 brief（当时"阶段 0"），不随进度改写。当前状态见 `docs/STATE.md` 末尾小节与 `docs/handoffs/HANDOFF.md`（唯一交接）。

## 目标

在纯仿真中完成宇树 G1 的全身动作模仿（动作跟踪），并在固定地面上加入受控外力扰动，评估鲁棒性与恢复能力。用户为机械专业背景、编程与仿真入门级，希望以"带练"方式理解每个环节，而不是只看结果。

## 约束

- 本地硬件：RTX 3060 Laptop 6GB、WSL2 Ubuntu 22.04、主机 16GB 内存（WSL 默认 7.6GB）、磁盘可用 ~918GB。
- 无真机；每周约 12 小时；不预付费云资源（如需必须用户确认配置与预算）。
- 只在 `supermimic-dsh` 内建产物；优先项目内隔离环境。
- 必须先核验官方身份，再决定是否复现；替代路线需比较后经用户确认。

## 阶段

0. 核验与环境基线（当前）
1. G1 仿真与现成策略回放（区分运动学播放 vs 动力学策略执行）
2. 参考动作与转换（人体骨架→G1：坐标、尺度、采样、限位、接触）
3. 训练理解与最小训练（冒烟测试：参数确实更新、检查点可回放；用户亲手改一个有意义的参数并先预测后对比）
4. 武术类动作跟踪（双足支撑、慢速、幅度适中，不含腾空/翻滚）
5. 受控扰动（固定地面；明确施力对象/坐标系/方向/大小/持续时间/动作阶段；区分力、冲量、改速度；先小扰动；统一协议）
6. 复现总结

## 评估指标（先定义再测）

动作完成率、摔倒率、关节/关键部位跟踪误差、根部位置姿态偏差、脚滑与异常接触、扰动后恢复时间、限位/执行器约束违反。单位、坐标对齐、摔倒与恢复判据必须在测试前写死。
