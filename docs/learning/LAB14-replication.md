# LAB14 — 同一配置重跑 3 遍：先测"噪声底"，再谈"凹坑"

> 前置：LAB13。旧文档写"四点 = 300 / 400 / 450 / 600"，倒地数/5：−x = 1 / 0 / 0 / 5，−y = 4 / 0 / 3 / 5。
> **但档位标签写错了**（见 §2 与 §2.5）：实际冲量是 40 / 45 / 60 / 120 N·s。按真实冲量重排：
> −x = 0 / 0 / 1 / 5，−y = 0 / 3 / 4 / 5——两个方向都单调，"更稳凹坑"是错标造成的假象。
> 这一轮真正要审的是：**40 N·s 的 0/5 与 60 N·s 的 4/5 能不能重复？**

## 0. 一句话

不加档位、不训练、不改判据，只把 −y 的两格（60 N·s 与 40 N·s，旧标签写作 300 / 400）用完全相同配置各重跑 3 遍
（5 种子 × 3 遍 = 30 次评估，约 15 min）。比较**同一格不同遍之间**的倒地数与逐种子判定。
先写预测，再看表。

## 1. 为什么先测重复性，而不是直接加种子

三句话：

1. 要审的差异是 60 N·s 的 4/5 倒 vs 40 N·s 的 0/5 倒——只有 4 个种子的距离；而每个种子在混沌区可能因为重跑而换轨迹。
2. 本机仿真不是位级确定的：D11 已记录 dance1 同种子两次 root 误差差 0.5%，S3 的摔倒步在 380–781 之间跳。
   fight 片段会把这点抖动放大成"倒 / 不倒"。
3. 先把**测量本身的误差**量出来，才知道 "4 vs 0" 里有多少可能是噪声。否则加种子只是给一台没标定的秤加砝码。

三种解释都能产生 "4 → 0"：

| 解释 | 预期表现 | LAB14 能区分吗 |
| --- | --- | --- |
| 真实效应（40 N·s 稳定、45 N·s 起陡升） | 同一格三遍都复现 0 与 4；40/60 两格稳定 | 能 |
| 重跑噪声 | 同一格三遍在 4/3/5 之间跳 | 能 |
| 5 种子太少 | 重跑稳定，但换 106–110 可能又不同 | 不能（留给 LAB15 的 ≥20 种子） |

关键区分：**LAB14 测的是"同种子重跑"的噪声，不是"不同种子"的分布。**
前者是"秤准不准"，后者是"这批样本的散布"；两者要分开写，不能互相替代。

**冲量口径（重要）**：格名里的 `j<N>` 是冲量 N·s，脚本据此算力 `F = j / 0.2`：

- `ny_j60` = 300 N × 0.2 s = **60 N·s**（Δv ≈ 1.80 m/s，按整机 33.34 kg）
- `ny_j40` = 200 N × 0.2 s = **40 N·s**（Δv ≈ 1.20 m/s）

前几轮文档把这两档写成 "300 / 400 N·s"：`300` 是 j60 的力，`400` 既不是 j40 的力（200 N）也不是冲量（40 N·s）。
`configs/perturb_protocol_v1.json` 的换算是准的（j60 = 300 N = 60 N·s）。**本讲义以格名为准**；回填报告时统一写成"力 × 0.2 s"。

## 2.5 按真实冲量重排之后，"凹坑"消失了

旧文档的排序假设是 300 < 400 < 450 < 600（把力当成冲量），而 `j40`/`j45` 的真实冲量其实**小于** `j60`：

| 冲量 (N·s) | 力 (N) | 旧文档标签 | −x 倒/5 | −y 倒/5 |
| --- | --- | --- | --- | --- |
| 40 | 200 | "400" | 0 | 0 |
| 45 | 225 | "450" | 0 | 3 |
| 60 | 300 | "300" | 1 | 4 |
| 120 | 600 | "600" | 5 | 5 |

按真实冲量排：−x = 0 → 0 → 1 → 5，−y = 0 → 3 → 4 → 5，**两个方向都单调**。
所以 LAB13 说的"400 比 300 更稳的凹坑"不成立：40 N·s 比 60 N·s 小，更稳是应该的；
真正陡的边界是 −y 的 40 → 45 N·s（0/5 → 3/5）和 −x 的 60 → 120 N·s（1/5 → 5/5）。
这使 LAB14 的对象更清楚：先确认 40 与 60 两端可重复，再把"40 与 45 之间陡不陡"留给下一轮。

## 5. 读数顺序（按这个顺序看）

1. 顶层 `replication.md` 的"每格 × 每遍"表：先看 down 那一列。
2. "逐种子判定"矩阵：同一批种子是"整列一起翻"还是"个别种子翻"。后者更像边界样本。
3. 连续量：down 只有 0–5 六档；`longest_dev_s` / 末尾 root 误差更细。
   三类判定没变但连续量在动，说明离边界不远，**别写"完全稳定"**。
4. 判读规则（写死，不要看到结果再改）：
   - 三遍倒地数**完全一致**（同数、同种子集合）→ 凹坑候选真实，进 LAB15；仍不能写"阈值"。
   - 倒地数一致但个别种子 class 互换 → 边界摆动，结论要注明"差在判定阈值附近"。
   - 差 **1 个种子（20%）** → 正好落在 5 种子分辨率上，**不能判定**真实或噪声；直接进 LAB15 加种子。
   - 摆动 **≥2 个种子** → 噪声主导：报告改为"概率 + 二项置信区间"叙事，种子补到 ≥20/格；禁止再画阈值曲线（D23）。
5. 与 LAB13 基线并列：`ny_j60` = 4 倒（种子 101/103/104/105），`ny_j40` = 0 倒（5 次全 transient）。

## 6. 常见坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| run 目录不是 lab14-replicate | 直接调了 lab12_recovery.sh 且没带 LAB14_TAG | 用 `scripts/lab14_replicate.sh` |
| 三层目录找不到 report | 顶层没有 `cell/seed`，只有 `rep<N>/cell/seed` | 顶层由 `lab14_compare.py` 汇总，别对顶层跑 lab12 report |
| 30 次太慢/超时 | 每次约 30 s，30 次约 15 min | 用后台 job 或按 rep 分两次跑（同一 `LAB14_RUN_DIR`） |
| 跑到一半断了 | 已写出的 `metrics.csv` 还在 | 用同一 `LAB14_RUN_DIR` 重跑（会覆盖同名 rollout） |
| 各遍种子不一样 | 手动改过 `LAB14_SEEDS` | 正式 run 三遍必须同一组 101–105 |
| 后台任务时另起 bash 报 EXECUTOR_UNAVAILABLE | dsh-ops 执行树竞争 | 等后台 job 结束再跑别的命令 |
