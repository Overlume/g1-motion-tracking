# LAB25 预测题：摩擦上界收敛

> 跑之前写，不要看结果再改。每题权重见括号，满分 8 分。
> 已知（都来自 LAB24/D38）：
> M4（默认 0.3–1.2）nx_j60 = 6/6/5（28%）、非倒地 root 中位 18.2 cm；
> f20（0.2–2.0，训练 seed 0）= 10/14/15（39/60，65%）、root 中位 68.7 cm；
> f30（0.2–3.0，训练 seed 0）= 0/0/0（0/60）、root 中位 18.7 cm（p75 38.6、max 61.8）、21/60 漂移；
> M4 的 ny_j60 = 19/18/18、ny_j45 = 11/11/12（LAB16/LAB17）。

**Q1（2 分）** 用同一个设置（0.2–2.0、3000 iter、4096 envs、热启动 model_49999）只换训练 seed（0 → 1），f20 seed1 在 nx_j60 上的三遍倒地数 k 大概是多少？给出「每遍 k 的范围 + 理由」。

你的答案：我觉得三遍的倒地数大概是14/15/13，我认为同一种配置的差别不大，也就是我举得f20现在的情况是正常的。

参考回答 / 判分：**0/2。**
实测 **5/5/4（14/60，23%，CP 13.4–36.0%）**，三遍都很稳，但只有 seed0（65%）的三分之一；vs M4（6/6/5）逐遍 Fisher p = 1.000/1.000/1.000，**统计上分不出**。
你答 14/15/13，方向恰好相反——本题考的就是「同一配置换训练 seed 差别有多大」，而 f20 的 65% 正是 seed0 的离群值。
唯一在 seed0/seed1 之间**复现**的是跟踪代价：非倒地 root 中位 68.7 → 71.4 cm，两遍的非倒地 rollout **全部**是漂移型（21/21、46/46）。

**Q2（2 分）** 同样只换训练 seed，f30 seed1（0.2–3.0）的 k 与非倒地 root 中位大概是多少？

你的答案：f30的三次k应该是0/0/0，非倒地的root中位置是20cm左右。

参考回答 / 判分：**1.5/2。**
实测 **1/3/3（7/60，12%，CP 4.8–22.6%）**，非倒地 root 中位 **27.9 cm**（逐遍 32.7 / 24.5 / 34.6）。
方向对（仍远低于 M4 的 28%）、幅度小错：你猜的三遍全 0 只在 rep1 成立；按讲义的判定线「每遍 ≤2/20 且 root ≤40」，
rep2/rep3 的 3/20 已经越线 → 只能算**部分复现**。root 27.9 仍 < 40，但比 seed0 的 18.7 明显变差，余量只剩一半。
补一个你没被告知的数：vs M4 逐遍 p = 0.091/0.451/0.695，**12% 与 28% 在 20 种子上不显著**；seed0 的 0/60 才是显著的（p = 0.020/0.020/0.047）。

**Q3（1 分）** f30（0.2–3.0）在 ny_j60 上的倒地率落在哪一档？（A）≤10/20 （B）11–15/20 （C）≥16/20

你的答案：我认为是（B）

参考回答 / 判分：**0/1。**
实测 **20/20/20（100%，CP 94.0–100%）**，答案是（C）；倒地的 20 个种子骨盆最低 0.101–0.111 m（全部落地），t_end ≈9.4–10.5 s。
正确推理：LAB16/LAB17/LAB23 里 −y 60 N·s 一直 ≥18/20，f30 连 −x 都没能压到 0，没有任何理由指望它在更难的 −y 上掉到 11–15。
这类题先看「这一档在已有数据里有没有下过 16」再猜。

**Q4（2 分）** 假设 f20 seed1 只有 4/20（与 seed0 的 65% 差 9 个种子），接下来你怎么设计实验来判断「2.0 档是真的差」还是「这两次训练都不稳」？写到能落地（几个训练 seed、每臂评估多少、用什么指标、怎么定判定线）。

你的答案：再增加5个seed进行训练，评估down rate和root error，和M4的基线相对比

参考回答 / 判分：**1/2。**
方向对（加训练 seed、看 down rate 与 root error、对 M4 基线），但缺三件能落地的要素：
1. **判定线**：例如「3 个训练 seed 的池化 k 都 ≥9/20（45% 且 95% 下界 > M4）」才算「2.0 真的差」；只要有一个 seed ≤4/20 就必须报 seed 间极差，不能给单点。
2. **评估协议**：每臂 20 种子 × 3 遍（边界格默认 ≥3 遍，D28/D30），报逐遍 k 与翻转种子；只跑 1 遍会被 D28 的翻转吃掉。
3. **指标与阈值**要写死：k（逐遍 + 池化）、非倒地 root 中位（池化口径）、漂移 ≥30 cm 占比。只写「down rate 和 root error」无法判。
另外成本：5 个 seed × 1 h 42 训练 + 60 次评估 ≈ 11 h；2 个（seed2、seed3）就够判「稳/不稳」，讲义 §6 的分支预案就是这个量级。

**Q5（1 分）** 本轮四个臂的结果，能不能直接证明「摩擦上界 2.0 比 3.0 差」？给出你判据（能 / 不能 + 为什么）。

你的答案：我认为是可以的

参考回答 / 判分：**0/1。**
**不能。** 三个理由：
1. 你说的「2.0 差」在同一训练 seed 内都不成立：seed0 是 65% vs 0%，seed1 是 23%（5/5/4）vs 12%（1/3/3）——两个 seed 的排名一致，但差距（42 与 11 个百分点）
   与 seed 间漂移（42 个百分点）同量级，20 种子的 Fisher 在 seed1 上 p = 0.09–0.70，**分不出**。
2. 能稳定复现的差别是**跟踪代价**（root 68.7/71.4 vs 18.7/27.9），不是倒地率；要说「2.0 比 3.0 差」必须限定成「跟踪更差」。
3. 要证「档位效应」，至少每档 ≥2 个训练 seed 并按 seed 报区间（本轮 f20/f30 各只有 2 个），单 seed 的 65% 已被证是离群。

1. **把单次训练当档位性质**——Q1/Q5 都是「同配置差别不大」的直觉，而本轮恰恰测出 seed 间差 42 个百分点。

3. **不先查已有数据的边界**——Q3 猜 11–15，而 −y 60 N·s 的历史数据从未低于 18/20。
