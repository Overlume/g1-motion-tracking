## 0. 目标与已知

### 0.1 一句话目标

用**零训练**的代价，把 f30（摩擦 0.2–3.0）在 **−y 方向**的 50% 倒地点从「只知道在 45–60 之间」收窄到 **±2.5 N·s 的格**，并同时给出非倒地 rollouts 的跟踪代价。

### 0.2 为什么要补 50 和 55

LAB25 的结论只有两个端点：

- f30 在 **45 N·s**：0/60（0%）——比 M4 的 34/60（57%）好得多，p < 1.5e-4。
- f30 在 **60 N·s**：60/60（100%）——和 M4 的 55/60（92%）一样全倒。

这两点合起来只能说明「3.0 档把 −y 边界**往高处推了**」，推了多少完全不知道：可能是 46 N·s（几乎没推），也可能推到 59 N·s（推到接近饱和）。**两个端点定不出一条曲线的形状**，而 D39 明确禁止再用「−y 无收益」这种一句话结论——所以要么补点，要么把结论写成 15 N·s 宽的区间。

补 50 与 55 之后，−y 曲线在 f30 上就有 4 个点（45 / 50 / 55 / 60），足以：

1. 用线性插值给出交点的点估计（精度 ≈ ±2.5 N·s）；
2. 判断曲线是**陡**（55→60 之间从 0% 冲到 100%）还是**平**（50 就已经 10–15/20）；
3. 顺带回答一个悬着的问题：**f30 在 −y 上的收益，是「真的更抗推」，还是「更早开始退让、所以不倒地」**（看表 2 的退让占比与 root 误差）。

### 0.3 三档读法（跑完先对号入座）

| 档 | 50 N·s | 55 N·s | 交点 | 怎么解读 |
| --- | --- | --- | --- | --- |
| **A** | ≤ 5/20 | ≥ 10/20 | 50–55 | 3.0 档把 −y 边界推高 ≈7–10 N·s，曲线斜率正常 |
| **B** | ≤ 5/20 | ≤ 5/20 | 55–60 | 曲线在 55→60 之间极陡；必须写「55 仍 0–5/20、60 全倒」，不许写「交点约 55」了事 |
| **C** | ≥ 10/20 | — | 45–50 | LAB25 的「−y 有效」幅度要下调，推高只有 ≈2–6 N·s |
| **非单调** | 55 的 k **小于** 50 的 k | — | 不插值 | 只报逐遍 k，不写交点 |

> 判据用**池化 k**（60 次里的倒地数），和 LAB24/LAB25 同口径。逐遍 k 的极差要一起报（D28/D39）。

### 0.4 成本

- 2 格 × 20 种子 × 3 遍 = **120 次**评估，实测 ≈34 s/次 → **≈1 h 10 min**。
- GPU 占用：单卡（RTX 3060 Laptop 6 GB），每次评估独占约 1.5 GB 显存。
- 没有训练、没有新 ckpt：ckpt 直接复用 LAB24 的 f30 产物。

### 0.5 本 lab 不做的事

- 不重训、不换 DR 档、不换动作、不改推的时机与时长。
- 不加种子数（仍是 101–120），不跑第 4 遍——翻转率已经由 LAB16/LAB17 量过，这里只关心 4 个点的位置。
- 不测 +y / ±x：那是另一条曲线，等 −y 闭环后再排。

## 5. 六个坑

1. **RUN=runs**：最贵的错。会把 README 之类的产物写进 runs 根目录，和 50 多个历史 run 混在一起（2026-11-20 已经踩过一次，靠手工搬家修）。脚本会拦，但别依赖它。
2. **尖括号不是占位符**：命令里凡是 <...> 都是「换成你的值」的说明，原样粘会被 bash 当成重定向（2026-11-20 踩过：RUN=runs/<YYYYMMDD>-00N-lab18-x70 直接报 No such file or directory，RUN 退化成 runs/）。
3. **忘了传 LAB26_RUN**：脚本没有默认 run 目录，不传就退出。每次调用（run / report / status）都要带同一个 LAB26_RUN=...。
4. **单遍下结论**：一遍 20 个种子里 k 差 1–2 是常态（LAB16：−x 60 三遍 6/6/5）。只报一遍会把翻转当成效应。
5. **把 k=0 当成「稳」**：LAB20b/LAB23 都出现过 k=0 但 root 80–90 cm 的「退让型」。看表 2 的 root 与退让占比，必要时看骨盆最低值（<0.2 m 才算触地）。
6. **不同 ckpt 混比**：交点只能同 ckpt 内插值；f30 的交点不能拿来和 M4 的 44 N·s 直接说「提高了 8 N·s」以外的结论（不同训练条件，样本也只有 1 个训练 seed，D39）。

## 7. 结果（跑完填）

- 时间线：开始 09:44:28，rep1 结束 10:04:44，rep2 结束 10:26:14，rep3 结束 10:47:29，总墙钟 **63.0 min**（120 次，31.5 s/次）。
- ny_j50：逐遍 k = **5 / 5 / 4**（池化 **14/60，23%**，CP 95% 13.4–36.0%），Fisher vs M4 = **0.00385 / 0.00385 / 0.00123**。
- ny_j55：逐遍 k = **20 / 19 / 19**（池化 **58/60，97%**，CP 95% 88.5–99.6%）。
- 表 2：ny_j50 非倒地 root 中位 **110.8** cm、退让 **46/46（100%）**；ny_j55 root 中位 **120.8** cm、退让 **2/2**（对照 45 N·s 是 87.2 cm / 49/60）。
- 交点：M4 ≈ **44.4** N·s（自检通过，与 LAB17 的 44.3 一致），f30 ≈ **51.8** N·s → 推高 ≈ **7.4** N·s。
- 三档判读：落在 **A** 档（50 = 23%、55 = 97%）——但要注意 55 已经饱和，所以这种「A」是「延迟」不是「抬高天花板」。
- 翻转：ny_j50 **5/20**（103 判据擦边；104/107/110/115 是骨盆 0.09–0.13 ↔ 0.46–0.49 m 的 rollout 双稳态），ny_j55 1/20（106）。
  三遍 k = 5/5/4 只差 1，但那是 ±1 翻转互相抵消 → 「k 稳定 ≠ 判定稳定」再次出现。
- 一句话结论：**3.0 档把 −y 的 50% 交点从 ≈44 推到 ≈52 N·s（+7），在 50 N·s 把倒地率从 75% 压到 23%，代价是非倒地 rollout 的 root 误差 22 → 111 cm、退让占比 100% —— 是「更晚被打倒」，不是「不倒」。**
