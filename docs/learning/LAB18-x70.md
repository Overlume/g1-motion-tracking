# LAB18 — −x 方向的第二个分点：70 N·s（20 种子 × 3 遍）

> 前置：LAB15（20 种子：−x 60 N·s 6/20）、LAB16（同种子 3 遍：−x 60 = 6/6/5，翻转 4/20，改写为 5–6/20）、LAB17（−y 过渡区用 45/50 两点定出交点 40–45，并测得过渡区中心翻转 3/20）。

> 你要产出：`runs/<今天的日期>-00N-lab18-x70/` 全套 + 结论 + 文档同步 + 提交。

## 0. 这个 lab 要达成什么

### 0.1 已知道什么

| 冲量 | −x 倒地 | 出处 | 可信度 |
| --- | --- | --- | --- |
| 40 N·s（200 N） | 0/5 | LAB13 | 5 种子、单遍 |
| 45 N·s（225 N） | 0/5 | LAB13 | 5 种子、单遍 |
| 60 N·s（300 N） | **5–6/20（25–30%）** | LAB15 + LAB16 | 20 种子 × 3 遍，翻转 4/20 |
| 80 N·s（400 N） | **20/20**（CI 下界 83%） | LAB15 | 20 种子、单遍 |

所以 −x 的 50% 交点只能在 45 N·s 之后、80 N·s 之前；已知 60 只有 25–30%，用 60/80 两点线性插值，交点 ≈ **66 N·s**。但这只是两点插值——**曲线在 60–80 之间是陡是缓完全不知道**。

### 0.2 本 lab 的目标

1. 给 −x 补第三个点（70 N·s），把「60 → 80」的两点夹逼变成三点，能估斜率与 50% 交点的区间（2 点只能插值，3 点才能看出曲率）。
2. 与 −y 做同口径对照：−y 现在有 40/45/50/60/80 五点（交点 ≈44 N·s），−x 补完 70 是 40/45/60/70/80 五点（交点估计 ≈66 N·s）→「两向边界不同」从「60 N·s 时 25% vs 95%」升级为「**50% 交点相差 ≈22 N·s**」的定量版本。
3. 检验「越靠近 50% 交点越不稳」是否也适用于 −x：60 翻 4/20；若交点在 66 附近，70 在交点右侧，翻转应该更少。若 70 翻转更多，说明翻转率不只由「离交点多远」决定，还与这一向的双稳态种子分布有关（LAB16 已发现 4 个 rollout 级双稳态）。

三种结果分别指向不同结论（这就是目标 1 的判据）：

| 70 的 k（三遍） | 含义 | 下一步 |
| --- | --- | --- |
| ≈ 15–20/20（75–100%） | 60→70 段很陡，交点紧贴 65–68 | 不必补点，交点写「65–70 之间」 |
| ≈ 8–14/20（40–70%） | 接近线性，交点 ≈ 66–72 | 不必补点；若 CI 与 60 重叠，过渡带写「60–75」 |
| ≤ 7/20（≤35%） | 曲线很缓，交点 ≥ 72 | 回补 75 N·s（再 60 次 ≈32 min） |

### 0.3 为什么补 70，而不是 55 / 65 / 75

- **60 与 80 的间隔是 20 N·s，70 是唯一天然中点**：二分法第一刀，信息量最大。补 65 或 75 只能得到「偏一侧」的一个点，仍要再补第二点才能定斜率；70 一次就能分出「陡 / 线性 / 缓」三档。
- **为什么不补 55**：60 已经只有 25–30%，55 只会更低；它离估计的交点（66）比 70 更远，对定位交点贡献小。而且 60 已有 4/20 判定翻转（含 4 个 rollout 双稳态），55 很可能整格摇摆，60 次预算买不到新信息。
- **为什么不补 90**：80 已经是 20/20（CI 下界 83%），再往上只会确认「已经打满」，不提供边界信息。
- **成本**：1 格 × 20 种子 × 3 遍 = **60 次**评估，单次约 32 s，每遍约 11 min，共约 **32 min**。这是目前最便宜的一格新信息。

### 0.4 与 LAB17 的分工

LAB17 解决的是「−y 的过渡带在哪」（45/50 两点）；LAB18 解决的是「−x 的过渡带是陡还是缓」。两向的边界差异只有各自都有 ≥3 个过渡带内点时，才能比较斜率，而不是只比较一个 60 N·s 的单点。

## 4. 常见问题与排查

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 找不到 checkpoint | 不在仓库根 / 用了别的 shell | cd 到仓库根再跑；脚本按相对路径找 ckpt |

## 5. 五个坑（每个都有人踩过）

1. **把 70 当「再确认一次 60」**：60 已经是 5–6/20，重跑 60 不会给出新信息；70 的价值在于它是 60–80 的中点。
2. **把 3 遍当 3 个独立样本**：统计单位是种子；3 遍只给「至少翻一次」的下界（D28）。
3. **只报 k 不报交点**：这个 lab 的成品是「交点 ≈X N·s（区间）」和「与 −y 差 ≈22 N·s」，k 只是原料。
4. **为了单调改判据**：判据（0.08 m / 13° / 10 帧）冻结（D21/D22）；不单调就是发现。
5. **跳过 README 先写 REPORT**：REPORT 的数字必须能从 run 目录反查到。
