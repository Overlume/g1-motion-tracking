1.同一冲量下，+x 与 +y 哪个更容易让策略失稳？为什么（提示：参考运动 8–8.2 s 时躯干朝哪个方向运动、速度多少）。

	答：运动 8–8.2 s 时躯干大致朝x方向运动、平移速度向量 (vx, vy, vz)	(−1.054, +0.624, −0.026) m/s
	那么在统一冲量下，+y更容易让策略失稳。因为这时候机器人大致往-x方向运动，+x的话两者相互抵消了。

2.失稳是阈值型（超过某档直接崩）还是渐进型（完成度连续下滑）？

	答：我认为失稳是渐进性。
	
	
3.j60（Δv 1.80 m/s）这一档，扰动后 1 s 内的 root 误差大约会到多少 cm？基线是 3.88 cm。

	答：我觉得大概是3.5cm左右。

4.如果 ±x 与 ±y 的失稳阈值差 2 倍以上，你能给出一个可能的物理解释吗？

	答：说明机器人在其中一个方向上的抵抗恢复性远差于另外一方，这可能跟机器人质心的分布有关、当然也可能跟当时的运动状态有关。
