# LAB23 预测题：DR 单档消融

> 跑之前写，不要看结果再改。每题权重见括号，满分 8 分。
> 已知：M4（默认 DR）nx_j60 = 5–6/20、非倒地 root 中位 18.2 cm、退让型 0/20、held-out 0.100；
> LAB20（三档同改）nx_j60 = 0/20、root 中位 93.4 cm、退让型 20/20、held-out 0.018。

**Q1（2 分）** 三个单因素臂（fric / com / bias）在 nx_j60 上分别大概倒几次（n=20）？

你的答案：我觉得分别是5，5，5.

参考回答（**得分 0/2**）：
- 实际：fric **2/2/2**（≈2/20）、com 13–15/20（72%）、bias 19/19/19（95%）；M4 是 5–6/20。
- 你的「5，5，5」三点全错：真实情况不是「三臂差不多」，而是**朝两个极端分开**（摩擦档好约 3 倍，另两档差 2.6–3.4 倍）。
- 满分要答出这种分化：摩擦改的是**接触力上限**（和 300 N 推力同一量级）→ 能帮上忙；质心改**重力矩杠杆**、编码器只加**观测噪声** → 都不会让人更容易站住。
- 判分细则：三臂都在 5 附近但方向对（如 2/12/18）给 1/2；三点方向全错给 0/2。

**Q2（2 分）** 哪个臂的 held-out 完成度最低？给一个数值区间（三选一：≈0.02 / ≈0.05 / ≈0.10）。

你的答案：我认为是bias，因为这个在机器人运动过程中的作用较小，DR增强后对机器人是否摔倒起的作用较小。

参考回答（**得分 1/2**）：
- 实际：三臂**全部 0.018**（±0.0004–0.0005），**没有「最低」之分**。你答的区间 ≈0.02 是对的。
- 关键判读：任何一档 DR 加强都足以把 held-out 从 0.100 打到 0.018（≈官方权重 0.016）→ 0.100 是「训练窗口邻近帧的记忆」，不是可迁移能力。
- 你的理由不成立：held-out 是**跟踪完成度**，不是摔倒率；而 bias 臂恰好是失败率最高的（95%）。
- 得分：数值区间对得 1 分，归因错扣 1 分；答「三臂一样 → 说明是共性」可给 2/2。

**Q3（1 分）** 哪个臂的「非倒地 root 误差」涨得最多？为什么？

你的答案：我认为是com，质心的偏移会引起机器人动作的不稳定，会导致机器人在世界坐标系当中偏移

参考回答（**得分 0.5/1**）：
- 实际排序：**bias 130.7 cm** > com 89.5 > fric 81.2（M4 18.2、LAB20 93.4）。
- 你的因果方向对了一半：com 确实会让世界系位置偏移（89.5，第二），但最大项是 bias——它不改动力学、只让观测更嘈杂，策略学到「按更差的观测动作」，被推后更容易走偏且回不来。
- 0.5 分给「选第二名」；满分要答「bias：观测噪声不改变可达集，只降低反馈质量」。

**Q4（2 分）** 如果只有一臂同时做到「nx 失败率下降」且「held-out 不明显下降」，你会怎么用它推进下一步训练？写出具体的下一组实验。

你的答案：增加迭代次数和DR范围

参考回答（**得分 0/2**）：
- 实际**没有**这样一臂：fric 失败率降了（10%），但 held-out 也掉到 0.018——三臂一样，所以「held-out 不明显下降」在这套协议里无从比较（都到地板了）。
- 正确推进方式：接受 fric 是唯一候选，做**摩擦档强度扫描**——下界固定 0.2，上界取 1.4 / 2.0 / 3.0（或改下界 0.2 / 0.1 / 0.05）；每档训练 1 h 40 + nx_j60 60 次评估 ≈37 min。
- 判据：失败率 ≤10% **且**非倒地 root 中位从 81 cm 压到 **≤40 cm**（否则只是把「摔倒」换成「被推走」）；不再用 held-out 当主指标（已在地板）。
- 你的「增加迭代次数和 DR 范围」不是实验设计：没有自变量取值、没有判据，且迭代次数在三臂间本来就相同，不是变量。

**Q5（1 分）** 如果三臂都 0/20 且退让型都高、held-out 也都不崩，你会怎么写结论？

你的答案：这三个因素有互斥关系，只有单独一个调大才能增强机器人的抗倒能力。

参考回答（**得分 0/1**）：
- 前提根本没发生：三臂是 6/43/57，held-out 全崩，没有一臂 0/20。
- 若真出现，写法应是：「三臂都 0/20 且 transient 全为退让型（root ≥30 cm）→ 不倒地是退让的普遍副作用，与档位无关；held-out 全崩 → 0.100 本身是脆弱的窗口记忆；D35 的『−x 有效』降级为『−x 更容易退让』。」
- 你答的「三因素互斥，只有单独一个调大才能增强抗倒能力」是假设而非结论写法，也没覆盖 held-out 崩的归因。
