# LAB24 预测题：摩擦档强度扫描

> 跑之前写，不要看结果再改。每题权重见括号，满分 8 分。
> 已知：M4（默认摩擦 0.3–1.2）nx_j60 = 5–6/20、非倒地 root 中位 18.2 cm；
> LAB23 fric（摩擦 0.2–1.4，只有摩擦加强）= 2/2/2（6/60）、root 中位 81.2 cm、54/54 漂移型；
> LAB20（三档同改，摩擦也是 0.2–1.4）= 0/60、root 中位 93.4 cm、60/60 退让型。

**Q1（2 分）** 三个臂（f14 = 0.2–1.4、f20 = 0.2–2.0、f30 = 0.2–3.0）在 nx_j60 上的倒地数（n=20）大概各是多少？给出顺序与数值。

你的答案：f14,f20,f30在nx_j60上的倒地数分别是2，0，0

**参考回答**：f14 2/2/1（池化 5/60 ≈ 6–8%，与 LAB23 的 6/60 一致）、f20 **10/14/15（65%）**、f30 0/0/0。两端之间不单调，中间那档反而最差——这是本题的关键。
**得分：1/2**。f14（2/20）与 f30（0）都对，f20 判成 0 与实测差 13–15 个种子。

**Q2（2 分）** 放宽摩擦上界（1.4 → 2.0 → 3.0）会把「非倒地 root 中位 81 cm 的漂移」压下去吗？说清你的机制（为什么压得下去 / 压不下去）。

你的答案：我认为压得下去，因为摩擦力增大，机器人想要在世界中移动的难度增加，那么在被推后漂移的幅度将会变小。

**参考回答**：会压下去，但机制不是「评估时摩擦变大」——**评估期 DR 一个字没改**（仍是 0.3–1.2），变的是训练分布：上界抬到 3.0 后，策略学会用更大的接触力 / 更硬的支撑在被推后把站位找回来，所以非倒地 root 中位 82.3 → 18.7 cm、max 109.5 → 61.8。正确写法是「训练时见过的摩擦范围改变了策略的恢复方式」。而且它不单调：f20（0.2–2.0）反而 65% 失败。
**得分：1/2**。方向对（f30 确实压下去了），但把摩擦当成评估期的物理量，没意识到只改了训练分布。

**Q3（1 分）** 三臂的「非倒地 root 中位」大致落在哪个区间？（A）<40 cm （B）40–60 cm （C）60–90 cm

你的答案：我觉得是（B）40–60 cm 

**参考回答**：（A）<40 cm。f30 是 18.7 cm（p75 38.6、max 61.8），f14 的 82.3 与 f20 的 68.7 才算（C）60–90。因为三臂不单调，不能把三臂中位数折中成 40–60。
**得分：0/1**。

**Q4（2 分）** 如果 f30 的倒地被数反而 >10%（即放宽上界让失败率回升），你的下一步会改哪个变量？写到能落地的程度（变量名 + 取值 + 为什么）。

你的答案：我认为可以在f20的基础上调整com，因为三者同时增大边界时，倒地数是0.

**参考回答**：前提没发生——f30 是 0/60。若真出现失败率回升，下一步也不该改 com（LAB23 已证质心档单独加强是 72%、反向）：先核 status/params 与 ckpt sha，排除续训或选错权重的工程问题；再在同一摩擦档复训 1–2 个 seed，判「档位本身不稳」还是「这一次训练崩了」；确认回升后把上界从 3.0 折回 2.5 做插值，并且每次都报三数（k、非倒地 root 中位、漂移占比），不再动 com / bias。
**得分：0/2**。前提判断错，且给出的下一步是已被 LAB23 证伪的方向。

**Q5（1 分）** 这三臂（只改摩擦区间）能区分「摩擦让机器人更站得住」和「摩擦让策略更敢动（更激进、被推后冲得更远）」吗？给出至少一个判据。

你的答案：可以的，通过改变摩擦上界来看非倒地root中位的变化，这可以说明摩擦对机器人被推后反应，这正是摩擦改变的功劳。

**参考回答**：不能只用一个判据。至少三条同时看：(a) k（失败率）；(b) 非倒地 root 中位 **加上** 漂移占比（≥30 cm 的比例）；(c) 同一 seed 三遍的离散度 / 是否 S↔T 翻转。f30 正是例子：root 中位 18.7 看起来「更站得住」，但 21/60 仍漂 ≥30 cm、seed107 三遍是 61.8 / 36.6 / 12.3 → 中位数掩盖了双峰，只报中位会把它读成「已解决」。
**得分：0.5/1**。用了 root 中位（必要条件），但当成充分证据。

错误模式（三条）：

1. **默认单调**：Q1 / Q3 都假设「上界越高越稳」，于是把中间档判成 0、把三臂折中到 40–60。实测是 8% → 65% → 0%，中间那档最差。
2. **把训练期参数当评估期条件**：Q2 的机制句就是这个错——评估协议一个字没改（同一 ckpt 之外的 DR 仍是 0.3–1.2）。
3. **用单一中位数当充分证据**：Q5 忽略了漂移占比与逐遍离散（f30 的 21/60 与 49.5 cm 极差），中位数会把「双峰」读成「解决」。
