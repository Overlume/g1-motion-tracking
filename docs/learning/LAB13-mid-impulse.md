# LAB13 — 找"必倒"的拐点：−x / −y 补 400 与 450 N·s

> 前置：LAB12。你已经有两条曲线上的四个点：
> −x：300 N·s = 4/5 恢复（1/5 倒）→ 600 N·s = 5/5 倒；
> −y：300 N·s = 1/5 恢复（4/5 倒）→ 600 N·s = 5/5 倒。
> 中间是空的。LAB13 就补这一格：**400 与 450 N·s**。

## 0. 一句话

不加新方向、不改判据、不重训，只在 −x 与 −y 两个方向各补两档冲量（400 / 450 N·s），
把"300 还能恢复、600 全倒"之间的拐点夹出来。20 次评估，约 12 min。

## 1. 为什么是这两档

三点理由：

1. **成本最低**：评估一次约 30 s，20 次 12 min；不需要重训。
2. **信息量最大**：现在 −x 的拐点在 (300, 600) 区间、−y 在 (300, 600) 区间，各补两点就能把区间缩到 1/6。
3. **和 +y 的口径对齐**：+y 已经有 5 档（15/20/25/27/30 N·s，即 0.45–0.90 m/s），可以给"崩/起倒/全倒"三级结论。
   −x/−y 现在只有两点，报不出三级。补到四点后至少能说"某档起 100% 倒"。

**为什么不是 350 / 500？** 350 太靠近 300（可能 5/5 恢复，信息量小）；500 离 600 太近（可能 5/5 倒，同样浪费）。
400（+33%）与 450（+50%）落在几何中间附近，最有可能命中"开始倒"的区间。

## 5. 读法

1. **先把四点排成曲线**（每个方向：300 / 400 / 450 / 600 的倒地数）：
   −x 预计 1 → ? → ? → 5；−y 预计 4 → ? → ? → 5。
2. **看 −y 有没有"饱和"**：若 400 就 5/5 倒，说明 −y 的必倒下界在 300–400 之间，450 是废点（正常，别删）。
3. **看 −x 的斜率**：从 4 恢复跳到 5 倒，如果发生在 400→450 之间，说明这个方向是"悬崖型"；
   如果 400 就 3 倒、450 全倒，则是"渐变形"。两者对"抗扰"的解释不同。
4. **注意 20% 分辨率**：5 个种子，1 个种子的差别就是 20%。**别把 4/5 与 5/5 的差别当成物理结论**。
5. **回看 LAB12 的反直觉结论**：若 −x 450 就 5/5 倒，而 −y 400 才 5/5 倒，那么 −x 的"必倒下界"反而**更高**，
   与"−x 比 −y 抗扰"一致；但若 −x 400 就全倒，则 LAB12 里 −x 300 的 4/5 恢复只是"刚好在阈值下"，
   不能说 −x 方向更抗扰。

## 6. 常见坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| run 目录名不是 lab13-mid-impulse | 直接调了 `lab12_recovery.sh` 且没带 `LAB12_TAG` | 用 `scripts/lab13_mid_impulse.sh`，它已设好 TAG |
| `report` 找不到目录 | 同名 tag 下还没有 run | 先 `run`；或用 `LAB12_RUN_DIR=...` 指定 |
| 报"未知方向: nx_j40" 之类 | 格名必须是 `<方向>_j<整数>` | 检查拼写：`nx_` / `ny_` + `_j40` |
| 冲量算错 | `j<N>` 是 N·s（力 = N/0.2 s） | j40 → 200 N；j45 → 225 N |
| 想比较两次 run | 两次 run 的 tag 不同，`show` 只显示最新 | 用 `LAB12_RUN_DIR=` 指定具体目录 |
