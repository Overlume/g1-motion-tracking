> 当前事实：冲量 60 N·s（力 300 N × 0.2 s）时 −y 倒 4/5、−x 倒 1/5；80 N·s（400 N）时两向都 5/5。
> 讲义与脚本：`docs/learning/LAB15-boundary20.md`、`scripts/lab15_boundary20.sh`、`scripts/lab15_report.py`。

## 0. 为什么还要加种子

LAB14 已经证明：同种子重跑，判定一个都不变（30/30）。所以 4/5 与 1/5 的差别**不是噪声**。但"不是噪声"离"能下结论"还差一步：

- 5 个种子时，4/5 的 95% 区间是 [28%, 99%]，1/5 是 [0.5%, 72%]。**两个区间大面积重叠**——所以现在只能写"−y 倒得更多"，不能写"−y 明显更脆"。
- 一个种子 = 20%；想让"12/20 vs 8/20"这种差别有意义，分辨率至少要 5%。

**置信区间怎么读**（Clopper–Pearson）：它是"如果把这个实验重复无数次，真实倒地率会落在这个范围里的概率是 95%"。
样本少时区间必然宽——20/20 的 95% 下界也只有 0.83，所以**永远不能从有限次实验写"100%"**。

## 5. 五个常见坑

1. **把 k/20 的百分比差当效应**：12/20（60%）vs 8/20（40%）看起来差 20%，Fisher p ≈ 0.34，根本不显著。
2. **把"CI 重叠"当"没有差异"**：重叠只是没分辨出来，不是相等。
3. **忘了 20 种子仍然只有一个相位/一个波形/一个作用点**：结论只能限定在这套协议里。
4. **把 20/20 写成 100%**：下界 0.83。
5. **和旧 run 混着报**：本次是独立 run 目录，必须注明来源，不要和 LAB12 的 5 种子数字混在一句话里。
