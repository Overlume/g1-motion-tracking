**参考答案要点（更正版）**

1. 先对齐口径：`j<N>` = 冲量 N·s；旧文"400/450 N·s"若指力，就是 80/90 N·s。写报告一律写"冲量 X N·s（力 Y N × 0.2 s）"。
2. 单调性只在"同方向、同种子集、同窗口"的相邻档之间谈；两档都 5/5 就说明到顶了，12.5% 的更细档没有信息量。
3. 5/5 ≠ 100%：5 个种子的 5/5 只给出 p(down) 的 95% 下界约 0.48（Clopper–Pearson）；写"某档起 100% 倒"必须加种子或重复。
4. 已测边界：−x 与 −y 的 5/5 都从 **80 N·s（400 N）** 开始，边界夹在 **60–80 N·s**；过渡区 −y 更弱（45 N·s：3/5 vs 0/5；60 N·s：4/5 vs 1/5）。
5. 结论永远带口径：5 种子、单时刻（8.0 s）、单波形（0.2 s 方波）、单作用点（torso_link）、终止关、推后看 3 s。
