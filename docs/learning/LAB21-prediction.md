## 背景（够用就行）

- M4 的 actor 输入 160 维，位姿信息全是「相对参考」的（anchor 位置+朝向误差），没有绝对位姿。
- LAB21 只加两项：机器人根世界坐标（3 维）+ 世界系线速度（3 维），actor 变成 166 维；其余全同 M4。
- 基线（同协议、同 10 种子 101–110）：train **0.999**、held-out（同片段后 20 s）**0.100**、unseen（另一片段）**0.025**。

### 参考回答（完整版）

- **Q1（2）**：0.999。训练片段本来就是天花板（10/10 全 0.999），只加 6 维观测、其余口径不变，专精不该掉；掉了才说明新输入在干扰。
- **Q2（2）**：**0.018**。理由是历史证据：LAB20 把三项 DR 加强后 held-out 也正好是 0.018（= 官方权重 0.016 的水平）。held-out 的 0.100 来自「同一段动作相邻窗口」的记忆外溢，任何改变策略输入结构/分布的做法都可能把它打掉；而在单片段训练下，追加原始绝对坐标只能增加「片段标签」信息，不会带来可迁移能力。诚实写法：区间 0.015–0.030，方向偏下降。
- **Q3（1）**：**A 偏 C 之间的「floor 噪声」**——最准确的答案是「0.03 上下、误差更差」，因为两个策略在 unseen 上都只活 0.5 s 左右。要点是：unseen 处于地板，不能拿它当泛化证据。
- **Q4（2）**：held-out 最可能变（同一坐标系、同一段动作），train 最不容易变（已到天花板）。机制必须写「绝对坐标被当作片段内相位/身份标签」，而不是「训练过 / 没训练过」。
- **Q5（1）**：不能。三个理由：单训练 seed；单片段训练（绝对坐标没有可迁移语义）；本轮还有扩维后归一化统计退化的实现问题。要证明「观测是瓶颈」至少需要多片段训练 + 2 个训练 seed + 跨片段评估。

### 错误模式

1. **默认「多给信息 = 更好」**：Q2 直接沿用基线 0.100，忽略 LAB20 已经证明这个数会归零。
2. **只答窗口不答机制**：Q4 只写「held-out」，没有说明为什么，也没有预判方向。
3. **把地板当刻度**：Q3 的 0.025 → 0.038 在模型里几乎不可区分，要求先说明地板在哪，再谈涨跌。
