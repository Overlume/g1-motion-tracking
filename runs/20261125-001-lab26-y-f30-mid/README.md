# LAB26 −y 50/55 N·s（f30 = 摩擦 0.2–3.0，20 种子 × 3 遍）

- 目的：LAB25 只给了端点（45 = 0/60、60 = 60/60），补 50 与 55 定位 3.0 档的 −y 50% 交点。
- 假设：50 落在 0–5/20，55 落在 5–15/20（交点 50–55，推高 ≈7–10 N·s）。
- 配置：ckpt model_52998（sha 前 8 位 1119f986）、fight1_s3_000s_20s.npz、终止关、8.0 s 起推 0.2 s、种子 101–120、3 遍。
- 命令：见 docs/learning/LAB26-y-f30-mid.md §2。
- 结果：**ny_j50 = 5/5/4（14/60，23%）、ny_j55 = 20/19/19（58/60，97%）→ 交点 ≈51.8 N·s（M4 ≈44.4），推高 ≈7.4 N·s**；非倒地 root 中位 87.2 → 110.8 → 120.8 cm、退让 82% → 100%。
- 下一步：−y 交点已在 ±2.5 N·s 内定位；如需 ±1 N·s 需在 50–55 内补 52.5 并加种子（优先级低于 P8/P7）。

## 4. 判读

1. **3.0 档在 −y 上确实有效，但幅度是「延迟 ≈7 N·s」**：交点 44.4 → 51.8；到 55 N·s 已经 97%、60 N·s 100% —— 它没有把边界推到饱和之外，只是右移了一小段。
2. **曲线形状被压缩**：M4 是宽曲线（40 → 0%、45 → 57%、50 → 75%、60 → 92%），f30 是陡曲线（45 → 0%、50 → 23%、55 → 97%、60 → 100%），斜率约 15 pp/N·s。所以「同冲量下更稳」与「边界更高」是两件事，后者只有 ≈7 N·s。
3. **代价随冲量单调变大**：非倒地 rollouts 的 root 中位 87.2 → 110.8 → 120.8 cm，退让占比 82% → 100% → 100%。即 3.0 档在 −y 上买到的每一次「不倒」，都是「被打退 1 m 以上再站住」。
4. **过渡区翻转最密**：ny_j50（23%，接近 50% 交点）翻转 5/20，ny_j55（97%，饱和）只有 1/20 —— 与 LAB17（−y 45 = 58% 时翻 3/20）同向，支持「越靠交点越不稳」（D28/D30）。
5. **−y 的档位效应与 −x 的比较**：−x 在 60 N·s 是 30% → 0%（LAB20b，退让 root 93 cm）；−y 在 50 N·s 是 75% → 23%、代价 root 111 cm。两向都是「用跟踪换不倒」，−x 的幅度更大。

## 5. 局限

1. f30 仍是**单训练 seed（seed 0）**；LAB25 已证明同档位换 seed 会让 −x 从 0% 变 12%，所以「23%」应读作「这个 ckpt 的 23%」，不是「3.0 档的 23%」。
2. 交点 51.8 是**跨陡段插值**（23% → 97%），真实不确定度 ≈±2 N·s；要更窄需补 52.5 并加种子。
3. 翻转 5/20 说明单遍 k 的误差 ≈±1–2 个种子；报告里所有 k 都带三遍。
4. 评估仍是单一动作（S3 0–20 s）+ 单时刻扰动（8.0 s），未扫步态相位；退让型的判定阈值（0.5 s / 30 cm）是事后选定（D36）。
5. 55 N·s 只有 2 次非倒地，root 120.8 cm 的样本量太小，只能定性。
