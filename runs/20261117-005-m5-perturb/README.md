# run 20261117-005-m5-perturb — M5 受控外力扰动（torso_link，世界系 ±x/±y）

- 目的：给特化策略 `model_52998` 施加已知冲量，测“多大会失稳、方向有没有区别、能不能恢复”。
- 设计：`torso_link` 上世界系恒力 0.2 s，窗口 8.00–8.20 s；档位 j30/j60/j120 = 30/60/120 N·s = Δv 0.90/1.80/3.60 m/s（整机 33.34 kg = g1.xml 30 个 body 质量求和）。
- 组合：4 方向 × 3 档 × 5 种子（101–105）= 60 次评估；基线 = LAB09 `m4_train`（无扰动，5 种子）：完成度 0.999、root 3.88 cm。
- 命令：`bash scripts/m5_perturb.sh run` → `bash scripts/m5_perturb.sh report`；补齐 −x 用 `M5_RUN_DIR=runs/20261117-005-m5-perturb M5_COMBOS="nx_j30 nx_j60 nx_j120"`。

## 结果

| 方向 | j30 (0.90 m/s) | j60 (1.80 m/s) | j120 (3.60 m/s) |
| --- | --- | --- | --- |
| **+x** | 未终止；后 0–1 s 13.2 cm（13.0–14.3），1–2 s 回落到 5.3 | 未终止；后 0–1 s 28.1 cm（27.6–29.0），1–2 s 回落到 9.5 | **终止 @8.38 s**（8.36–8.40） |
| **−x** | 未终止但恢复慢；后 0–1 s 38.3 cm（37.6–38.6），1–2 s 仍 25.3 | **终止 @8.50 s**（8.48–8.52） | **终止 @8.24 s** |
| **+y** | **终止 @8.62 s**（8.60–9.22） | **终止 @8.44 s** | **终止 @8.18 s** |
| **−y** | 未终止但恢复慢；后 0–1 s 54.4 cm（49.0–57.2），1–2 s 仍 34.7 | **终止 @8.24 s**（8.22–8.24） | **终止 @8.16 s** |

“终止 @x s” = 扰动后首个 reset 落点（片子全长 19.98 s，无扰动时 reset 在 19.94 s 的 motion_end）。终止格完成度一律 0.57–0.59：reset 把 motion 相位归零后只剩约 590 步预算，最多走到第 590 帧，**它只标记“被打断过”，不是“跟踪了一半”**。扰动窗口内就 reset 的格子，后 0–1 s root 误差属于新一回合，不可比（`m5.md` 里标 `*`）。

## 三条结论

1. **失稳是阈值型的，方向阈值差 ≥ 2 倍**：+y 在 0.90 m/s 就崩；−x / −y 落在 0.90–1.80；+x 落到 1.80–3.60。排序 **+y ≪ −x ≈ −y ≪ +x**。
2. **“没终止”≠“没事”**：+x j60 扰后 1 s 的 root 误差 28.1 cm（基线 7 倍），−y j30 更差（1 s 54.4 cm、2 s 仍 34.7 cm）。终止阈值与恢复质量是两个独立维度。
3. **失败极快**：所有终止都在 8.14–8.62 s，即推力结束后 0–0.4 s（≤20 控制步），没有“踉跄后站稳”的过程；与 LAB09“换窗口即崩”同源，说明策略没见过这类状态。

## 物理解释（tentative）

- 8–8.2 s 躯干速度约 (−1.05, +0.62) m/s：+x 是制动方向，+y 与运动同向。
- 支撑面在前后（x）长、左右（y）窄，质心高约 0.7 m → 侧向静稳定裕度小，y 轴推力普遍更危险。
- 但 −y（侧向、且与运动 y 分量反向）与 −x 阈值相当，说明除“相对运动方向”外还有步态相位的作用；单施加时刻无法分离 COM 分布与相位效应。

## 局限

1. 单训练 seed 的策略；阈值分辨率只有 3 档，只能给“落在哪两档之间”。
2. 只测 8.0 s 一个施加时刻。
3. 只在 S3 训练片段上测；结论不可外推为“G1 抗扰能力”（D17 规则 4、D19）。
4. 冲量换算用整机质量近似，未计扰动点位置的角动量分配（torso 3.81 kg，占整机 11%）。
5. 终止格内 R-MPKPE 3.97–4.38 是 reset 后新回合的数字，不能当作扰动后的姿态质量。
