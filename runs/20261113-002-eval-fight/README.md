# 20261113-002 — 官方预训练策略跟踪 LAFAN1 fight 片段（量化评估）

## 目的

同一 checkpoint（`scratch/model_49999.pt`）、同一评估脚本（`scripts/eval_tracking.py`）、同一种子（seed=0），把动作从 dance1 换成 fight1 片段，看"泛化到没见过的动作类别"会掉多少。

## 命令

```bash
MUJOCO_GL=egl environment/.venv/bin/python scripts/eval_tracking.py \
  --checkpoint-file scratch/model_49999.pt \
  --motion-file data/processed/fight1_s2_134s_20s.npz \
  --seed 0 --out runs/20261113-002-eval-fight
```

## 结果对照（官方预训练策略，seed=0）

| 指标 | dance1（131.5 s，runs/20261112-001-eval） | fight1 片段（20.0 s，本 run） | 变化 |
|---|---|---|---|
| 完成率 | 1.000 | 1.000 | — |
| 跌倒 | 否 | 否 | — |
| MPKPE 均值 (cm) | 10.74 | 11.73 | +9% |
| MPKPE p95 (cm) | 17.43 | 22.87 | +31% |
| R-MPKPE 均值 (cm) | 3.42 | 8.18 | **+139%** |
| 关节位置 RMSE (rad) | 0.108 | 0.301 | **+179%** |
| 关节速度 RMSE (rad/s) | 0.950 | 3.798 | **+300%** |
| pelvis 倾角误差均值 (°) | 2.56 | 7.55 | +195% |
| pelvis 高度均值 (m) | 0.743 | 0.655 | −0.088 |
| 脚滑（左/右，cm） | 448 / 547（131 s） | 64 / 13（20 s） | 单位时间反而更低 |

## 解读

1. **没有摔倒、也没中途终止**：说明学到的平衡策略对打斗站架有基本鲁棒性。
2. **姿态层面的退化是主要问题**：R-MPKPE 3.42 → 8.18 cm、关节 RMSE 0.108 → 0.301 rad（≈17°），说明手臂/腿的细节跟不准，不只是"整体漂移"。
3. **MPKPE 只涨 9% 而 R-MPKPE 涨 139%**：因为 dance 的 MPKPE 大头是根节点漂移（10.74 vs 3.42 的差值），fight 片段只有 20 s、漂移还没来得及累积，所以总误差看着变化不大——这再次说明**必须分开看漂移与姿态**。
4. **pelvis 平均低 8.8 cm**：机器人整体蹲得更低，是"跟不上剧烈动作时用屈膝换稳定"的典型表现，也是 MPKPE 的一部分来源。
5. 关节速度 RMSE 涨 3 倍：参考里挥拳、转身的瞬时角速度很高（最大 42.5 rad/s），策略输出平滑得多 → 打斗的"爆发感"丢了。

## 局限

- 只有 20 s、单一 seed、单一 subject（subject2）；不代表 LAFAN1 全体。
- 参考动作的物理可行性未验证（重定向误差会直接计入跟踪误差）。
- 脚滑指标跨不同时长不可直接比较（本表按总量列出，未归一化）。
