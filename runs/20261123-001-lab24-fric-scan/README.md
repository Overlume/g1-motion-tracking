# LAB24 摩擦档强度扫描（nx_j60，20 种子 × 3 遍）

- 目的：LAB23 的 fric 臂（摩擦 0.2–1.4）把 −x 失败率降到 10%，但 54/54 非倒地全是「漂移型」（被推走 81 cm）。
  本实验**只沿摩擦档加深上界**，问：放宽到 2.0 / 3.0 能否把漂移压回去，同时失败率不回升。
- 假设（写预测时）：上界越高，策略越敢用接触力，被推后更容易原地找回；但 k 可能回升。
- 判据（D37 决定 4）：k ≤10% **且** 非倒地 root 中位 ≤40 cm 才算「摩擦上界是杠杆」。

## 5. 判读

1. **非单调，三数并列**：0.2–1.4 → 8%、0.2–2.0 → **65%**、0.2–3.0 → 0%。既不能写「摩擦越大越稳」，也不能写「越高越好」；f20 的反常只有单训练 seed，不能当「非单调定理」（§6）。
2. **只有 3.0 档同时满足 D37 判据**：k 0/60、root 中位 18.7 cm（≈ M4 的 18.2，对比 f14 的 82.3），p75 38.6、max 61.8、没有一次 >80 cm。
3. **但 f30 不是「漂移解决」**：21/60（35%）仍漂 ≥30 cm、13/60 >40 cm；同一 seed 三遍的 root 极差可达 **49.5 cm**（seed107：61.8 / 36.6 / 12.3），110 是 55.6 / 35.1 / 9.5 → 判定（S/T）与轨迹双不稳。
4. **k ≈65% 时 3 遍不够**：f20 逐遍 10 → 14 → 15，5 个种子（101/104/106/108/110）**全部 rep1 transient → 后两遍 down**（101：T 0.26/79.9 → D 0.62/53.8 → D 0.62/52.8；108：T 0.24/119.2 → D 0.78/45.4 → D 0.78/45.6）。与 LAB18 的「rep1 down → 后两遍 transient」方向相反，说明这是逐遍漂移、不是固定的首遍效应。
5. **f14 复跑 5/60 vs LAB23 6/60**：同一 ckpt、同协议，差 1 个种子且可解释（seed119）→ 边界格自检容差写 5–6/60，差 ≥2 个种子才排查。
6. **单看失败率会误判 f20**：它失败率最高（65%），但幸存者的 root 中位 68.7 反而比 f14（82.3）低——「站不住」与「跟得上」在这组臂里是两件事，必须报三数（D35/D36/D37）。

## 6. 局限

- 每档只有 **1 个训练 seed**（seed 0）：f20 的 65% 与两侧（8%、0%）不自洽，可能是该次训练不稳定，也可能真实非单调——现有数据分不开。
- f30 的 k=0 是「39 擦边 + 21 漂移」的混合，不是全稳；三型阈值（0.3 / 0.5 s、30 cm）是事后选定（D36/D37）。
- 评估仍是单一动作（S3 0–20 s）＋单时刻扰动（8.0 s 起推），未扫步态相位；ny 方向未在本轮复测（LAB23 三臂都 20/20）。
- 训练条件指标与抗推无相关性，所以不能靠 tfevents 选档。
