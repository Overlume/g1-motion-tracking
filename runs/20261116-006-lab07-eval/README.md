# LAB07 权重扫描结果：单调下降 + 姿态代价从 1.0 之后开始

动作 S3，四个臂各 300 iter（4096 env、seed 0、从 scratch/model_49999.pt 续训），评估 5 种子 101–105，同脚本、同协议。唯一变量：`motion_global_root_pos` 的 weight，std 固定 0.3。

## 2. 形状：root 单调下降但斜率每档减半；姿态在 1.0 触底后回升

**root 误差**（cm）相对上一档的改善：−10.66 → −5.14 → −2.77。每翻一倍权重，收益几乎减半，外推地板在 ~20 cm 附近。这是典型的**边际递减**，不是 U 形。

**姿态**（R-MPKPE，越小越好）在 weight=1.0 触底（5.98），之后回升：1.5 为 6.10（+2.0%，在 4% 评估噪声内），2.5 为 6.45（**+7.9%**，已超出噪声）。同一方向的还有：joint_vel_rmse 1.22 → 1.33（单调变差）、左脚滑移 99.6 → 159.5（2.5 比 1.0 差 **60%**）、joint_rmse 在 2.5 达到 0.1849（全表最差）。

**反直觉的一点**：tilt 误差在 2.5 反而最好（4.04，全表最低），且训练回合长度在 2.5 明显变短（166.9 vs 199.6）。说明 2.5 档不是"摔倒/站不稳"那一类退化，而是**动作变形**：为了贴住世界位置，身体更激进的倾斜与拖脚（滑移翻倍），姿态精度下降。

## 3. 判读：M4 用 weight 1.5

| 候选 | 得到 | 付出 |
| --- | --- | --- |
| 1.0 | root 30.86 | 姿态 5.98 |
| **1.5** | root 25.72（比 1.0 再好 16.7%） | 姿态 6.10（+2.0%，噪声内）、滑移 139.7 |
| 2.5 | root 22.95（比 1.5 再好 10.8%≈2.8 cm） | 姿态 6.45（+7.9% 出界）、滑移 159.5（+14%）、joint_rmse/joint_vel 全表最差 |

决定：**M4 用 1.5**。理由：位置收益在 1.5 仍在噪声之上（16.7%），姿态代价仍在噪声之内（2.0%）；到 2.5 时位置只多换 2.8 cm，姿态、滑移、关节速度三项同时出界——这是"用模仿质量换位移"的临界点，不宜作为主策略配置。**不做 3.5**：趋势已经清楚（每翻倍收益减半、姿态代价单调上升），再花 35 分钟只是把同一条曲线延长。

| 题 | 你的预测 | 实测 | 判 |

| Q1 形状 | 单调下降；且 1.5 之后会过度关注世界位置、牺牲朝向与关节 | root 单调下降 ✓；R-MPKPE 在 1.0 后回升 ✓；但"最先受影响的是朝向"不准（yaw 在 1.5 最好，2.5 才变差） | 方向对 |

| Q3 哪段改善更大 | w1.0 vs w0.5 更大 | −25.7% vs −16.7% | 对 |

Q2 的错值得记一句：**tilt 不是灵敏的"代价探针"**。它是姿态的一部分，却在更强的位置奖励下反而改善（身体更倾斜、更贴地）。真正的探针是 R-MPKPE（根相对姿态）、关节速度与滑移——这三个在本机多次实验里都先动。

## 5. 局限

1. 每个臂**只训练 1 个 seed**（seed 0），训练侧噪声未量化；4–5% 的判决边界（1.5 vs 2.5 的 10.8% 是出界的，1.0 vs 1.5 的 16.7% 也是出界的）在单 seed 下只能当"强趋势"。
2. 评估级噪声底 ≈4%（同配置重跑 43.34 vs 41.52）；本表相邻档差 10.8% / 16.7% / 25.7% 都超出，所以排序可信，但**具体数值不要当精确值引用**。
3. 只有 300 iter（官方预算 0.6%）；权重最优点会随训练变长而移动，M4 的结果要与此表并读，不能直接宣称 1.5 全局最优。
4. S3 既是训练集也是评估集，结论不外推到未见动作。
5. 评估只跑 20 s（999 步），长时漂移未测。
