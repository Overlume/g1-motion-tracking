# LAB18 — −x 70 N·s 第二分点（20 种子 × 3 遍）

- 目的：给 −x 补 70 N·s，三点（60/70/80）估斜率与 50% 交点；与 −y 的交点 ≈44 N·s 同口径对照。
- 假设：70 落在 8–14/20（40–70%），交点 ≈66–72 N·s；翻转不会多于 nx_j60 的 4/20。
- 配置：ckpt model_52998（sha 前 8 位 fc8f975b）、fight1_s3_000s_20s.npz、终止关、8.0 s 起推 0.2 s、种子 101–120、3 遍。
- 命令：见 docs/learning/LAB18-x70.md §2。

## 判读

- **50% 交点在 65–70 N·s 之间（中位插值 ≈68）**：60 N·s 取 LAB16 中位 6/20 = 30%、70 取本批中位 11/20 = 55%，线性插值 60 + 10×(0.5−0.30)/(0.55−0.30) = 68；用遍均值（28.3%→58.3%）得 67.2；用逐遍上下界得 65–70。
- **与 −y 的 ≈44 N·s 相差 ≈23–24 N·s**：两向边界不同，现在是「交点位置差」，不再只是「同一冲量上的比例差」。
- **两向曲线形状不同**：−y 在 40→50 就完成 0→75%，−x 到 60→70 才从 25–30% 走到 55%；两者都在 80 打满。−x 的过渡带更靠右，且 70 这一格本身仍有 45 个百分点的 CI 宽度。
- **翻转不是对称噪声**：4 个翻转全部是「rep1 down → 后两遍 transient」，逐遍 k 单调下降（14→11→10），101–105 同样 5/5→3/5→3/5。与 LAB16/17 的混杂方向不同；首遍偏倒的机制未确认（可能是首遍与后续的 GPU 热/时钟状态差异，也可能是随机），所以 k 一律按区间报。
- **对假设的检验**：讲义假设「70 落在 8–14/20」，实测 14/11/10 —— 上界命中、后两遍低于假设下限；「翻转不会多于 nx_j60 的 4/20」实测正好 4/20。

## 局限

- 单格单方向的第二分点，仍是单一 ckpt（model_52998）、单一时段（8.0 s）、单一波形（0.2 s 方波）、单一作用点（torso_link）。
- 4/20 的翻转完全集中在 rep1，若这是系统性首遍效应，则「3 遍」对这类格仍不足以给出稳定的中心估计——需要用「换顺序再跑一遍」来区分（未做）。
- 交点是用三点线性插值估的，没有拟合曲线模型；65–70 是插值区间，不是置信区间。
- 翻转 n/20 的单位是种子，3 遍只给「至少翻一次」的下界（D28）。
