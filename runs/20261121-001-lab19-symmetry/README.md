# LAB19 — 四向对称性：+x / +y 在 60/80 N·s（4 格 × 20 种子 × 3 遍）

- 目的：补齐 +x / +y 的 60 与 80 N·s，把「两向边界不同」扩成四向同口径对照；检验 80 档「20/20」是否只对 −x/−y 成立。
- 假设（用户预测）：px_j60 = 12/12/12、py_j60 = 20/20/20，py 更脆；py 与 ny 对称（差 1–2 个）；px_j80 = 15/15/15；翻转最多的是 px_j60。
- 配置：ckpt model_52998（sha256 fc8f975b…8ceed9）、`data/processed/fight1_s3_000s_20s.npz`、终止关、8.0 s 起推 0.2 s、种子 101–120、3 遍、格 px_j60 px_j80 py_j60 py_j80（力 300 N / 400 N）。
- 命令：见 `docs/learning/LAB19-symmetry.md` §2。三遍分别为 10:00:57–10:42:10、10:42:10–11:23:23、11:23:23–12:04:47，合计 **2 h 4 min**、240 次评估（均值 31 s/次）。
- 规范：判定同 LAB12（三分类 stable/transient/down，判据冻结）；四向全部 3 遍、同种子、同 ckpt。

| px_j80 | 80 N·s（400 N） | **0 / 0 / 0** | **0%** | [0%, 16.8%] | 1 stable（seed101）+ 19 transient（崩了都恢复），最长偏离中位 0.20 s |

- 101–105 子集：px_j60 0/5 ×3、px_j80 0/5 ×3、py_j60 5/5 ×3、py_j80 5/5 ×3（LAB12 没有 +x/+y 的 20 种子基线，只记录不比一致）。

## 判读

1. **同一冲量 60 N·s 下，四向从 0% 走到 100%**：+x 0/20、−x 5–6/20、−y 18–19/20、+y 20/20 → 边界顺序（脆弱→稳固）**+y < −y < −x < +x**。决定倒地的不只是冲量大小，方向至少同等重要。
2. **x 轴符号差最大**：60 档 0% vs 25–30%、80 档 0% vs 100%。「两向边界不同」升级为「四向边界不同」（D32）。
3. **y 轴两侧几乎对称**：+y 20/20 vs −y 18–19/20（差 1–2 个种子），但两者都是最脆的两向；LAB11 姿态审计「collapse 全在 +y」由此得到定量印证。
4. **+x 是最抗推方向，「80 起全倒」对它作废**：60 全 stable（无 transient），80 仍 0 down（19 transient 都能恢复 + 1 stable）；结合 LAB12 的 120 N·s（5 种子里 2 稳、3 down），**+x 的 down 边界落在 80–120 之间**（未定位）。
5. **翻转 0/80 与「离边界越远越不翻」一致**：4 格都远离判据边界（k = 0 或 20），而 LAB16/17/18 里 k 在 40–60% 的格翻 3–4/20 → D28 的三档规则得到直接对照。

## 局限

- 单一 ckpt（model_52998）、单一时段（8.0 s）、单一波形（0.2 s 方波）、单一作用点（torso_link）；+x/+y 只测了 60/80 两档，120 仍是 LAB12 的 5 种子单遍。
- 翻转 0/80 只说明这 4 格「远离判据边界」，不能推广成「+x/+y 的判定都稳定」——边界带（k 在 40–60%）尚未取样。
- **机制未验证**：+x 为什么稳、+y 为什么最脆（推的方向相对运动方向、支撑相/摆动相、脚底接触），本批没有证据，只给现象。
- 3 遍的统计单位是种子（D28），0/80 的 CP 上界 5% 是「至少翻一次」的下界估计。
