# 20261122-003-lab23-dr-ablation：DR 单档消融

## 1. 目的与假设

LAB20 把三档 startup DR 同时加强后得到两个结果：held-out 完成度 0.100 → 0.018（D34）、−x 60 N·s 失败率 30% → 0% 但扰动后 root 误差 18.7 → 92.9 cm（D35/D36）。三档同改，无法归因。

**问题**：三档里哪一档造成 held-out 崩塌？哪一档换来「不倒地」？

**假设**：单因素臂会把收益与代价拆开——某个档负责「不倒地」、某个档负责「跟踪下降」；若三臂都造成 held-out 崩塌，则说明崩塌与档位无关，是「训练分布变宽」的普遍结果。

## 2. 协议（与 M4 / LAB20 一致，每臂只改一档）

| 项 | 值 |
| --- | --- |
| 热启动 | `scratch/model_49999.pt`（sha f1bc404f…f22319） |
| 训练 | Mjlab-Tracking-Flat-Unitree-G1，3000 iter，4096 envs，seed 0，S3 0–20 s |
| 臂 | `fric` 摩擦 0.2–1.4 / `com` 质心 ±4/6/6 cm / `bias` 编码器 ±0.02 rad（其余两项回默认 0.3–1.2、±0.025/0.05/0.05、±0.01） |
| ckpt | 每臂 `model_52998.pt`（sha：fric 603fe363…f9e945、com 3e1ba2ed…a965ae3、bias e31c3160…b00111） |
| 扰动 | nx_j60 / ny_j60（300 N × 0.2 s），torso_link，8.0 s 起推，终止关，推后看 3 s |
| 扰动种子 | 101–120；nx 3 遍、ny 1 遍 |
| held-out | `data/processed/fight1_s3_120s_20s.npz`，10 种子 101–110，999 步 |

已核对：三臂的 `params/env.yaml` 里只有一档被改（fric：摩擦 (0.2,1.4) 且质心 ±0.025、bias ±0.01；com：质心 ±0.04 且摩擦 0.3–1.2、bias ±0.01；bias：±0.02 且摩擦 0.3–1.2、质心 ±0.025）。三臂 ckpt sha 互不相同、也不等于热启动权重。

## 5. 结果（nx_j60 池化 60 次；ny 1 遍 20 次）

| 臂 | nx k（逐遍） | nx 池化 | 非倒地 root 中位 (cm) | 漂移型 | 退让型 | ny k/20 | held-out（10 种子） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| M4 | 6/6/5 | 17/60（28%） | 18.2 | 0 | 0 | 19/18/18 | 0.100 |
| LAB20（三档） | 0/0/0 | 0/60 | 93.4 | 0 | 60 | 20/19/20 | 0.018 |
| **fric** | **2/2/2** | **6/60（10%）** | **81.2** | **54/54** | 0 | 20/20 | **0.018** |
| com | 13/15/15 | 43/60（72%） | 89.5 | 17/17 | 0 | 20/20 | 0.018 |
| bias | 19/19/19 | 57/60（95%） | 130.7 | 2/3 | 1/3 | 20/20 | 0.018 |

- 三型分解（transient 与非倒地 rollout）：**擦边型** = 偏离 ≤0.3 s 且 root <30 cm；**漂移型** = 偏离 <0.5 s 但 root ≥30 cm（人没倒、没明显下沉/倾斜，但被推走）；**退让型** = 偏离 ≥0.5 s 且 root ≥30 cm。fric 的 54 次非倒地**全部**是漂移型（骨盆最低 0.418 m、非倒地 root 中位 81.2 cm），bias 的 3 次非倒地里有 1 次退让、2 次漂移。
- 24 个臂-遍-p 值：fric vs M4 逐遍 p = 0.235/0.235/0.407（池化 6/60 vs 17/60，p = 0.019）；com vs M4 逐遍 p = 0.0562/0.0104/0.00385（池化 p = 3.6e-6）；bias vs M4 逐遍 p = 3.93e-5/3.93e-5/1e-5（池化 p = 7.4e-15）。
- 图：`outputs/figures/lab23_dr_ablation.png`（三面板：倒地率 / 非倒地 root / held-out）。

## 6. 判读

1. **held-out 与档位无关**：三臂都掉到 0.018（fric 0.018±0.0004、com 0.018±0.0005、bias 0.018±0.0005），与 LAB20 的 0.018 同值。所以 0.100 是极度脆弱的「窗口记忆」：**任何一档** DR 加强（哪怕只加摩擦）都足以把它清零，D34 说的「三档同时加强」不是必要条件。
2. **−x 的唯一收益来源是摩擦档，但它是「漂移式」**：fric 6/60（10%）vs M4 17/60（28%），池化 p=0.019；逐遍 2/20 vs 6/20 p=0.235（单遍不显著，靠三遍方向一致）。代价是 54/54 非倒地 rollout 被推走 81.2 cm（骨盆 0.418 m、无倾斜）→ 「不倒地」确实成立，但「跟得住」没有。
3. **质心与编码器档反而显著变差**：com 43/60（72%，p=3.6e-6）、bias 57/60（95%，p=7.4e-15），bias 的骨盆最低到 0.056 m（真摔）。所以「加强 DR 更鲁棒」在这两档上**反向**：把观测误差或质心不确定性加大，只会让 −x 更容易倒。
4. **LAB20 的 0/60 + 60/60 退让 不是单档能复现的**：单档摩擦是「漂移」（dev 0.3 s、root 81），三档叠加才是「退让」（dev 0.76 s、root 93）。三档之间存在交互，不能用「每档各贡献一点」的线性叙事。
5. **训练指标无法预测抗推表现**：三臂训练末的 anchor 误差与 root 奖励几乎一样（0.17–0.21 / 0.18–0.22），但 −x 失败率分别是 10% / 72% / 95%。→ 以后不能用训练曲线证明「鲁棒」。
6. **−y 没有收益**：三臂都 20/20（M4 19/18/18），与 LAB20b 的结论一致。

## 7. 局限

1. 单训练 seed（seed 0）、单动作片段；臂间差异没有训练侧方差。
2. 每档只测了一个强度（LAB20 的强度），没有强度分档，无法排除「该档在更弱/更强时方向不同」。
3. 漂移型/退让型阈值（0.3 s / 0.5 s / 30 cm）是事后选定（D36/D37）；分类型计数会随阈值移动，但三臂之间 54 vs 17 vs 2 的差距远大于阈值敏感性。
4. held-out 只有 1 个窗口、10 个种子；0.018 已是地板，不能区分「0.017 与 0.019」的细微差别。
5. 没有独立的触地指标（骨盆 <0.2 m 帧数），bias 臂的「真摔」是用 pelvis_z_min 0.056 m 判的。

## 8. 事故与偏差

- 无评估事故。用户是分批跑的（每臂单独一次 `run`），根目录 `params.txt` 只记录最后一次的 `arms: bias`；每臂 `perturb/rep1/params.txt` 是权威记录（含各自 ckpt sha 与 cells/seeds）。
