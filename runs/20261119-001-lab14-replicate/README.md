# LAB14 重复实验：同配置重跑 3 遍 → 判定层 30/30 一致

**日期**：2026-11-19 16:48–17:03（约 15 min）｜ **策略**：`model_52998`（M4，weight 1.5，sha256 `fc8f975b…ceed9`）｜ **动作**：`data/processed/fight1_s3_000s_20s.npz`
**规模**：2 格 × 5 种子 × 3 遍 = 30 次评估；终止关（`--ignore-terminations`）、推后看 3 s；判据与 LAB12 完全相同
**命令**：`LAB14_TAG=lab14-replicate bash scripts/lab14_replicate.sh run`（每遍写 `<run>/rep<N>/`，顶层 `replication.md/json`）

## 0. 目的与假设

D23/D24 之后，"−y 60 N·s = 4/5 倒、80 N·s = 5/5 倒"是效应还是重跑噪声？若重跑本身就能摆动 ≥1 个种子（20%），
则"边界夹在 60–80"不可判，必须先加种子。预期：本评估无 DR、同 seed 同初始状态，重跑应当稳定；但 GPU/浮点
非确定性可能让"判据附近"的样本翻转。

## 1. 结果

| 格 | 冲量 | rep1 | rep2 | rep3 | 倒地种子 |
| --- | --- | --- | --- | --- | --- |
| `ny_j60` | 60 N·s（300 N × 0.2 s） | 4/5 | 4/5 | 4/5 | 101, 103, 104, 105（102 始终 transient） |
| `ny_j80` | 80 N·s（400 N × 0.2 s） | 5/5 | 5/5 | 5/5 | 101–105 |

极差 0、种子互换 0：**倒地数、倒地种子集合、以及唯一那个 transient 的种子（102）三遍都不变**。
与 LAB13/LAB13b 基线（`runs/20261119-001-lab12-recovery` 的 ny_j60、`runs/20261119-001-lab13b-true-mid` 的 ny_j80）也完全一致。

## 2. 数值层并非位级复现

判定一致不代表数字一致。同一格同一 seed 的三遍（原值见各 `rep<N>/recovery.json`）：

| 量 | ny_j60 seed101 | ny_j60 seed105 |
| --- | --- | --- |
| `pelvis_z_min` (m) | 0.091 / 0.102 / 0.113 | 0.129 / 0.129 / 0.117 |
| `root_err_end_cm` | 212.0 / 215.0 / 215.0 | 209.4 / 209.4 / 215.7 |
| `longest_dev_s` | 3.08 / 3.08 / 3.08 | 2.14 / 2.14 / 2.48 |

即：骨盆最低点抖动约 ±1 cm、末尾 root 误差 ±3 cm、最长偏离 ±0.34 s。仿真不是位级可复现（GPU 归约顺序 / 浮点），
但抖动幅度远小于"4/5 → 5/5"这一级差异。

## 3. 结论

1. **重跑噪声（判定层）= 0**：这 30 次里，同配置同 seed 的分类零变化。M5 里各格 20% 的差别不是重跑噪声，是 5 个种子的抽样差异。
2. 因此**"再跑一遍看看"不能提升分辨率**，只能加种子（N=20 → 5% 粒度）。
3. 但这只证明了"远离婚判据的样本"稳定：本 run 的 4 个 down 格与 1 个 transient（seed102 最长偏离 1.10 s，阈值 0.20 s，5 倍余量）
   都离阈值很远。**恰好压在判据上**的样本（如 LAB12 `px_j120` seed104，最长偏离恰 0.20 s）仍可能被 ±0.34 s 的抖动翻转——
   本轮没有测到这一类。
4. 口径（D25）：报告可以写"60 N·s 有 1/5 恢复、80 N·s 5/5 倒，重跑 3 遍不变"，不能写"边界 = 60–80 N·s 已确定"，
   因为 5/5 的 p(down) 95% 下界仍只有 0.48（Clopper–Pearson）。

## 4. 局限

- 只测 −y 方向的两格；−x 未做重复（LAB12 的 −x 60 是 4/5 恢复，方向相反，值得同样测一遍）。
- 5 种子 = 20% 分辨率；测的是重跑噪声，不是种子分布。
- 单一施加时刻（8.0 s）、单一波形（0.2 s 方波）、单一作用点（torso_link）、固定 ckpt。
- 逐次原始文件（`<cell>/seed<S>/{metrics.csv,eval.log,summary.json}`）受 `.gitignore:24 runs/*/*` 排除，只在本地；本 README 记录的
  判定与数值取自 `replication.json` 与各 `rep<N>/recovery.json`（均已入库）。
