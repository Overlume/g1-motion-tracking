# LAB22 参考动作脚底接触 / 穿地校验（M2 遗留项）

- 目的：给 M2 补物理可行性证据——参考动作的脚底穿地深度、接触比例、悬空时长；Part B 看策略骨盆是否比参考高。
- 假设：训练用片段（s3_000s）存在 2 cm 级穿地或 3 cm 级悬空；策略骨盆 offset 在 ±2 cm 内（跟着参考走）。
- 输入：4 段 npz（s3_000s / s3_120s / s2_134s / dance1）+ G1 MJCF（febdcbef）+ M4 评估的 metrics.csv。
- 命令：见 docs/learning/LAB22-foot-contact.md §2。
- 结果：**4 段里 3 段 FAIL**——s3_000s 59.6 mm（p99 38.6、接触 34%、最长悬空 3.82 s）、s2_134s 59.0 mm、dance1 53.3 mm；只有 held-out 段 s3_120s 合格（16.7 mm）；Part B：M4 骨盆比参考**低 1.70–1.76 cm**（|Δ|>2 cm 占 47–48%）→ 策略在「往下够地面」。
- 下一步：把「参考不可行成分」写进 root 误差的解释；重定向下游加闸（max 穿地 ≤20 mm），见 D41。

## 4. 判读

1. **重定向产物系统性不落地**：4 段里 3 段穿地 >50 mm，训练用的 s3_000s 是 59.6 mm（p99 38.6 mm = 每 100 帧里有 1 帧陷近 4 cm）。
2. **两种偏差同时存在**：s3_000s 的脚底 p50 是 **+2.8 cm**（中位帧悬空），但 p1 是 **−3.9 cm**（最差 1% 陷地）→ 参考的高度曲线整体上下漂，不是单纯「抬太高」或「压太低」。
3. **fight1 三段的漂移是 GMR 高度标定问题，不是机器人模型问题**：同一条流水线的 dance1 只飘 **0.8 cm**、接触 **90%**；而 fight1 三段飘 2.2–3.0 cm、接触 25–44%。
4. **策略侧的被动物理补偿只有 ≈1.6 cm**：骨盆比参考低 1.62 cm（|Δ|>2 cm 的帧占近一半），说明它「跟着参考高度、用腿去凑」，而不是整体悬空——与 LAB22 讲义 §0.4 的第一种假设一致。
5. **因此 M4 的 root 误差要拆**：3.90 cm 的均值里，至少有 1.6 cm 是「参考-机器人身体不匹配」（策略被迫下压），剩下 2.3 cm 才是跟踪本身；同理 held-out 0.101 / unseen 0.025 的完成度也建立在「追一个不可行参考」之上。
6. **判定 FAIL ≠ 数据作废**：训练与已交付结论仍然有效（策略确实在这段参考上学到了动作），但**不能**把 root 误差、完成度当「纯策略指标」引用；也不能把「更贴近参考」当成唯一优化目标。

## 5. 局限

1. 只测了 4 段、一个模型（G1 29 DoF）、一套脚底几何；换机器人或换重定向工具结论可能不同。
2. 「接触」是运动学几何判据（脚底 <20 mm），不是真实接触力；脚底 box 是薄板（z 尺寸 0），实际脚掌有厚度。
3. Part B 只用了 M4 在训练段的 5 个种子（plain eval，无扰动）；扰动后的 offset 未测。
4. 只有骨盆高度可从 metrics.csv 复原；**无法**从现有日志复原策略的脚底轨迹，所以「策略自己有没有穿模/悬空」仍未直接测量（sim 接触求解会阻止穿模，但会以关节偏差为代价）。
5. dance1 的 npz 无 fps 字段，秒数是按 50 fps 换算。
