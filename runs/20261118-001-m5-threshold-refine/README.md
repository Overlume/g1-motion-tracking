# 20261118-001 M5 阈值细化：+y 方向（15/20/25/27 N·s）

## 目的与假设

粗扫（`runs/20261117-005-m5-perturb`）给的是三档冲量：+y 在 j30（0.90 m/s）就终止，j60/j120 同样终止，于是只能写“+y 阈值 ≤ 0.90 m/s”。
本 run 把 +y 一侧补到 0.45 / 0.60 / 0.75 / 0.81 m/s，回答两件事：

1. 0.90 m/s 之前是否已经“打得动”策略（跟踪质量先崩，episode 尚未终止）？
2. 终止阈值落在哪一段：0.75 之前、0.75–0.81、还是 0.81–0.90？

## 协议（与 M5 完全一致，只改冲量档位）

- 施加点 `torso_link`，世界系恒力，窗口 8.00–8.20 s（0.2 s），片段中段。
- 整机 33.34 kg，`dv = J / 33.34`；`F = J / 0.2 s`。
- 评估脚本 `scripts/eval_tracking.py`：终止检测开、启动 DR 关、999 步、种子 101–105。
- 对象：特化策略 `runs/20261117-001-m4-w15-finetune/logs/g1_tracking/2026-11-17_09-25-17_m4-w15/model_52998.pt`
  （sha256 `fc8f975b7f6cbb223bccaa27a4edd63901a91518e69d2df9e94710d0fe8ceed9`）。
- 动作：`data/processed/fight1_s3_000s_20s.npz`（即训练片段——评估集=训练集，见 §局限）。

## 结论

1. **+y 有级联的两道阈值，不是一个点**：
   - 0.75 m/s（j25）起，**跟踪质量已经崩**（0–1 s 偏离 43 cm、峰值 74 cm），但 episode 不终止；
   - 0.81 m/s（j27）起，**开始出现终止**（1/5，且延迟到 10.46 s）；
   - 0.90 m/s（j30）**全部在 0.42 s 内终止**（5/5）。
2. **“没终止”不等于“没被影响”**：j25/j27 的 0–1 s 误差是基线的 11–14 倍，峰值 0.78–1.05 m（超过一个身长）。
3. **恢复方式是“先放弃、再追回”**：误差在 9–12 s 才回到 4–8 cm；j15/j20 也是到 10 s 之后才稳定在基线附近。
4. **终止 ≠ 倒地**：本次 20 格中 `fall_detected` 全为 False（`scripts/eval_tracking.py:178` 的判据是 `pelvis_z < FALL_HEIGHT` 连续 `FALL_STEPS` 步）。
   终止由跟踪项触发——j30 seed101 是 `anchor_pos`（root 位置误差超限，8.64 s），j60 seed101 是 `ee_body_pos`（8.48 s）。
   同期骨盆在 8.2–9.5 s 最低 0.41–0.52 m（深蹲/前倾）、倾角峰值 21–27°。
   **对照**：官方策略在 S3 上的 `runs/20261114-001…005` 是 `fall_detected=True` 的真倒地。
   两类失败不可直接对比，报告里一律写“终止/失稳”，不写“摔倒”。

## 局限

1. 评估片段 = 训练片段，结论只对“特化策略 + S3 000–20 s + 8.0 s 施加”成立（D17/D19）。
2. 每格 5 个种子；0.81 那一档只有 1/5 终止，属于“开始出现”，不是稳定比例。
3. 9–10 s / 10–12 s 的分桶中位只取了 3 个种子，用于描述趋势，不是统计量。
4. 未逐帧看视频核对“终止格”到底是不是真倒地；`fall_detected=False` 只说明骨盆没有持续低于阈值。
5. 只细化了 +y；−x/−y 仍只知道“0.90 存活、1.80 终止”，中间（约 1.2–1.6 m/s）未测。

## 本次改的脚本

- `scripts/m5_perturb.sh`：`force_vec` 由硬编码三档改为通用 `j<N>` → `F = N/0.2 s`（j30/j60/j120 行为不变）；新增 `M5_TIERS` 控制档位循环。
- `scripts/m5_report.py`：`TIERS` 改为 `tier_ns()` 解析；新增 `--tiers`、`--dirs`，缺失组合表不再写死 12 格。
- 新增 `scripts/m5_combined_plot.py`：把粗扫与细化 run 合并成一张图（左：存活回合的 0–1 s 误差，空心=该格有种子终止；右：存活比例）。
