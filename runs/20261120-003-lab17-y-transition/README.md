# LAB17 — −y 45/50 N·s 过渡区（20 种子 × 3 遍）

- 目的：把 −y 的 50% 交点压到 45–50 之间；复核 LAB13 的 45 = 3/5。
- 假设：45 落在 10–14/20（50–70%），50 落在 15–18/20（75–90%）；过渡区中心翻转 ≥ 60 N·s 的 1/20。

## 判读

- **50% 交点在 40–45 N·s 之间**：40 N·s = 0/5（LAB13，5 种子，CI 上界 52%）、45 N·s = 58%（[32%, 81%]），线性插值 ≈44.3 N·s。45 已是明显过半，不是「过渡起点」。
- **50 N·s 接近饱和**：15/20 三遍不变，与 60 N·s 的 18–19/20 只差 3–4 个种子 → −y 的过渡带是 40→50，不是 45→60（D30）。
- **过渡区中心最不稳**：`ny_j45` 翻转 3/20（15%），高于 `ny_j50`（0/20）与 LAB16 的 `ny_j60`（1/20）→ 越靠近 50% 交点越容易改判；D28 的「边界格 ≥3 遍」扩到过渡区全部格（D30）。
- LAB13 的「45 = 3/5」被 rep2/rep3 复现，不是 D27 式离群；但单遍仍会少算 1 个种子。

## 局限

- 40 N·s 仍只有 5 种子 0/5，不能倒推「45 以下必不倒」；
- 单一 ckpt（model_52998）、单一时段（8.0 s）、单一波形（0.2 s 方波）、单一作用点（torso_link）；
- 3 遍只给「至少翻一次」的下界，统计单位是种子（D28）；
- 倒地率用三遍均值（11.5/20、15/20）报。
