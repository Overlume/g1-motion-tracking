## 三条结论

1. **M4 的 3.90 cm 确认是特化**：同一 ckpt 换到同片段的 120–140 s 窗口，完成度 0.999 → 0.101（−90%），最长存活段 19.96 s → 2.02 s，5 个种子几乎不散（0.099–0.102），说明这不是“边境效应”，而是明确的分布外崩溃。
2. **对未见片段 S2，两条策略都不行**：m4 0.50 s / 官方 0.26 s。差别只有 2 倍，都远低于“会跟踪”。所以不能说“m4 泛化更好”，只能说“m4 对该动作类型有一点残余泛化”。
3. **在训练片段上，特化策略远强于通用策略**：完成度 0.999 vs 0.333，root 3.88 vs 82.83 cm，最长段 19.96 vs 6.66 s。官方策略不是“不会 S3”，而是会跑偏到 80 cm 后触发终止——这与 2026-11-14 的“官方 S3 5/5 摔倒”一致，只是那次用 `--ignore-terminations` 让它一直跑到摔（见下）。

## 用户预测判分（docs/learning/LAB09-prediction.md）

- **Q1（完成度约 0.1）**：数值完全正确（实测 0.101）。但你写明依据是“看了你的自测数据”——这是借用已知结果，不算独立预测；下次把依据换成机制（例如“训练只见过 0–20 s 的时序，换窗口等于换节律”）。
- **Q2（S2 上 M4 存活更久）**：对（0.50 s vs 0.26 s），理由“官方偏柔和舞蹈、M4 后训练于格斗”也站得住。补充一点：两者都远低于 1 s，所以这只是“残余泛化”的相对差，不是能力。
- **Q3（会出现 root 小但完成度小的格子）**：对，机制也说对了（“一开始就瘫软/持续时间很短”）。补一句更准确的说法：reset 把机器人反复丢回片头，所以 root 误差天然小——这是**指标失效**，不是“准”。
- **Q4（“训练效果显著，但泛化能力不足”）**：方向对，但还不够诚实。报告里应写成：“在训练片段上 root 3.88 cm / 完成度 0.999（in-distribution）；同片段未见窗口完成度 0.101、最长 2.02 s（held-out）”。**没有 held-out 数字就不能说“训练效果显著”**。

## 局限

1. 每个组合 1 个训练 seed 的策略（m4 只训了 seed 0），评估侧 5 种子；训练侧方差仍未量化。
2. held-out 只覆盖 1 个窗口 + 1 个片段；S2 片段本身“过快”（历史结论），失败可能叠加了速度因素。
3. `ee_body_pos` 终止阈值偏紧，可能是跨片段失败的最先触发项；未做阈值敏感性分析。
4. 终止原因全为 `ee_body_pos`，说明失败模式单一，但也意味着我们没看到“摔倒”这一更严重的失败类别。

## 对下一步（M5）的含义
