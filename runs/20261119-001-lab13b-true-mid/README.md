## 0. 为什么补这一轮

LAB13 名义上补"400/450 N·s"，实际格名 `j40/j45` 经 `force_of()`（`F = j / 0.2`）换算成 **200/225 N 力 = 40/45 N·s 冲量**，
比已有的 300 N（60 N·s）档还小，根本没落进 300→600 的走廊；"四点曲线 300/400/450/600"因此是力与冲量混写的产物。
本轮按旧文原意（400/450 = **力**）补真正的中间档：`j80 = 400 N × 0.2 s = 80 N·s`、`j90 = 450 N × 0.2 s = 90 N·s`。

## 3. 结论

1. **两个方向都单调**（按冲量或按力排序都一样）：−x 0/0/1/5/5/5，−y 0/3/4/5/5/5。旧"−y 更稳凹坑"作废，它是错标号造成的排序假象（D23 更正 → D24）。
2. **5/5 全倒从 80 N·s（400 N）开始**，两向一致；100% 区边界夹在 **60–80 N·s**（300–400 N）之间。90/120 只是饱和区内的重复。
3. **过渡区 −y 明显更弱**：45 N·s 时 −y 3/5 vs −x 0/5；60 N·s 时 4/5 vs 1/5。"−y 比 −x 更抗扰低"在 45–60 N·s 这一段有数据支持。
4. **5 种子限制**：5/5 不等于 100%；上表是"20 次里 20 次倒"的事实，不是 p(down)=1 的证明。
5. 机理未测：未看支撑多边形/质心，未扫施加相位；只能报该冲量下的计数。

## 3.5 为什么这次一个 transient 都没有

判分口径没变：同一脚本、同一阈值，`recovery.md` 的汇总表仍列 stable / transient / down 三列。20 次全部 `fall_detected = 是`
（骨盆 <0.15 m 连续 5 步），eval 在倒下处 break，所以都记 down：

- 数据结束 9.02–12.30 s（20 s 片段没跑完），末尾 root 误差 204–434 cm；
- 骨盆最低 0.060–0.131 m，最大倾角差 25.9–164.3°。

transient 需要"崩过、但没触发 fall 判据、末尾回到参考"；在 400/450 N（Δv 2.4–2.7 m/s）下没有种子满足。
上一轮 40/45 N·s（200/225 N、Δv 1.2–1.35 m/s）才是"崩了又恢复"的区间（17/20 transient）。

另外修了判分脚本的标题：以前写死 `# LAB12 恢复实验判分`，两份 recovery.md 看起来一样；现在写 `# 恢复实验判分：<run 目录>`。

## 5. 局限

1. 每格仍只有 5 种子；80/90 两档都 5/5，无法分辨 p(down) 是 0.6 还是 1.0。
2. 单一施加时刻（8.0 s）、单一波形（0.2 s 方波）、单一作用点（torso_link）、世界系。
3. 只测 40/45/60/80/90/120 六个冲量；30 N·s（j30）在本动作上未测。
4. fall 判据对"坐倒"与"侧倒"灵敏度不同：−x 的 seed104 骨盆只到 0.100 m、倾角 25.9°，属边界样本。
