# LAB12 恢复实验：关掉终止之后的 30 次

**日期**：2026-11-19 ｜ **策略**：M4 自己的 finetune（model_52998，weight 1.5）｜ **动作**：fight1_s3_000s_20s.npz（in-distribution）
**规模**：6 格 × 5 种子 = 30 次评估，termination 关闭（`--ignore-terminations`），推力 t=8.0 s 起、0.2 s、torso_link、世界系
**墙钟**：30 次共约 15 min（每 26–38 s）｜ **命令**：`bash scripts/lab12_recovery.sh run`

## 0. 一句话

M5 里"站着被判罚"的 31 次，在关掉终止、推后看 3 s 之后：**23 次倒在垫子上（22 次硬倒地 + 1 次临界）、5 次摔了一下又站回来、只有 2 次真正稳住**。
"upright_trip"不是一类东西，M5 的"抗扰"表述必须按这个比例重写。

## 1. 假设与目的

LAB11 的三分法有一个信息漏洞：姿态审计只读"复位前 0.4 s"，而 M5 的终止会在推后 0.14–1.22 s 复位，
所以 31 次 `upright_trip` 只被证明"复位那一刻还站着"（D21：结局未知）。

假设：**其中多数是"延迟倒地"**——推后先踉跄一下，误差触发终止，但真正倒地发生在复位之后。
检验方法：同一格、同一种子、关掉 termination、推后看 3 s，按骨盆高度 / 倾角逐帧判定。

## 4. 结论

1. **假设成立**：31 次 `upright_trip` 里 23 次（74%）是延迟倒地，只有 2 次真正稳住、5 次崩了又恢复。
   D21 的"结局未知"可以结束了，但"upright_trip = 站着"不能再用——它不是一类，而是两类。
2. **600 N·s（3.6 m/s 当量）对四个方向都致命**：−x/+y/−y 全 5/5 倒地，+x 5 次里 4 次没稳住（2 倒 + 1 临界 + 2 稳）。
   与 M5 的"高推力全部被判罚"一致，但更严重：**判罚 ≠ 判定，是真的躺下**。
3. **300 N·s 才分出方向差异**：−x 4/5 恢复 vs −y 4/5 倒地。
   M5 里这两格的终止时刻几乎相同（8.50 vs 8.44 s，中位），**但恢复能力完全不同**——
   说明"终止阈值"和"能不能站住"是两件事，不能用一个排序概括。
4. **倒地速度的排序**（t_end 中位）：+y 8.94 < −y 9.06 < −x 9.20 < +x（19.98/10.26–10.60）。
   与 M5 的终止阈值排序（+y ≪ −x ≈ −y ≪ +x）基本同向，但把 −x 从"≈ −y"里分了出来（−x 晚 0.14 s，且 300 N 时几乎全恢复）。
5. **恢复质量不是"恢复了就没事"**：−x 300 N 的 4 次恢复末尾 root 误差 15–26 cm（基线 3.88 cm），
   位置跟踪仍然很差；恢复只说明"没摔倒"。

## 5. 机制讨论（tentative，未做实验分离）

- 推后 0.06–0.24 s 就开始偏离（首次偏离 8.06–8.26 s），倒地发生在 0.9–2.5 s 之后 —— 中间是"踉跄/追赶"阶段。
- 600 N 时四个方向都超出可恢复范围，方向差异只剩"倒得快慢"（0.26 s 量级）。
- 300 N 时 −x 与 −y 分道扬镳，最可能的解释仍是**侧向支撑窄**（−y 把重心推出双脚连线外侧），
  而 −x 是沿运动方向的"制动"，脚还能前后调整。但本实验**没有**测质心投影与支撑多边形，也没有分离
  "推力方向"与"施加时刻的步态相位"，所以这只是相关证据，不是机理证明。

## 8. 局限

1. 只重跑了 6 个 `upright_trip` 格；其余 49 次（survived 39 + collapse 10）沿用 LAB11 的分类，没有一起重跑。
2. 只测 300/600 N·s 两档，±x/±y 四方向；100–250 N·s 的行为仍是空白。
3. 单一推力波形（0.2 s 方波）与单一施加时刻（8.0 s）——换时刻（步态相位）可能改变结论。
4. 判分阈值（0.08 m / 13° / 0.2 s / 8°）是从视频核对里定的，边界样本（+x 600 N 种子 104）会随阈值摆动。
5. "恢复"只判"站住了"，没判"恢复得多快、走没走回参考线"（末尾 root 15–26 cm 说明跟踪仍差）。
