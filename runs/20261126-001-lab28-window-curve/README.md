# LAB28 窗口距离曲线（dance1 的 6 个 20 s 窗口）

## 1. 目的与假设

- 目的：LAB27 证明「加一段同动作的其它窗格能把它从 0.061 抬到 0.108」，本 lab 问这份记忆的**作用半径**——同一段动作上，离训练窗口越远，增益还剩多少。
- 假设：(A) 单调衰减且远端收敛到 M4 → 有半径；(B) 只有 0 s 高 → 纯局部记忆；(C) 平台/不单调 → 距离不是主因。
- 设计：零训练，只换被评估的动作窗口。dance1（6574 帧 / 131.5 s / 50 fps）切 0/20/40/60/80/100 s 各 20 s；策略 M4（只训练过 fight1 S3 0–20 s）与 LAB27（训练过 fight1 S3 0–20 s + dance1 0–20 s）；种子 101–110；共 120 次。

## 5. 机制（零 GPU 追加分析，见 lab28_audit.md / lab28_audit.json）

### 5.1 曲线不是「随距离衰减」，两策略都非单调

LAB27 逐窗口：0.999 / 0.244 / **0.055** / 0.108 / **0.309** / 0.101 —— 中间 40–60 s 比 M4 还低，80–100 s 又跳高。M4 自己的基线也非单调：0.484 / 0.070 / 0.115 / 0.061 / 0.191 / 0.064（8 倍跨度）。

### 5.2 0 s 的 0.484 不是「M4 认识 dance1」，是这一窗最慢

参考关节速度（rad/s）：0 s **4.01**、20 s 8.29、40 s **13.05**、60 s 12.07、80 s 11.69、100 s 11.84。dance1 开头是慢段，完成度自然高。→ **完成度受窗口难度污染，不能直接当「记忆强度」**。

### 5.3 首段对齐误差（同一批参考帧，K = 双方首段最小值，≤200）

| 窗口 | K（帧） | MPKPE M4 → LAB27 | 差 |
|---|---|---|---|
| 0–20 s | 200 | 10.5 → **3.5** | −7.0 |
| 20–40 s | 28 | 15.4 → **4.0** | −11.4 |
| 40–60 s | 47 | 13.9 → 14.5 | +0.6 |
| 60–80 s | 34 | 17.8 → 15.4 | −2.4 |
| 80–100 s | 57 | 35.0 → **11.7** | −23.3 |
| 100–120 s | 46 | 11.2 → 10.3 | −0.9 |

对齐后增益出现在 0 s、20 s、80 s；40 s 与 100 s 基本没有。**整段 MPKPE 在 4/6 窗口「变差」（如 100 s 12.2 → 27.6）是存活更长的假象**（D42 决定 2 的老坑）。

### 5.4 内容新颖度比时间距离更能解释增益

新颖度 dmin（该窗口每帧到训练窗口 0–20 s 在归一化关节空间的最小距离，均值）：0 s 0.00、20 s 6.48、40 s 11.82、60 s 10.75、80 s 10.80、100 s 12.00。

- Spearman(距离, Δ) = **−0.600（p = 0.208）** → 不显著
- Spearman(新颖度, Δ) = **−0.886（p = 0.019）** → 越不像训练窗口，增益越小

⚠ n=6、窗口间不独立（相邻 20 s 重叠的内容），只能当提示。

## 6. 判读

1. **属 (C)**：曲线非单调，「记忆的作用半径」**不能用时间距离描述**；不能说「半径 <20 s」（20 s 处增益仍最大），也不能说「单调衰减到 60 s」。
2. **但「记忆确实跨窗口存在」**：5/6 窗口 LAB27 优于 M4，且 4 个窗口是 10/10 种子一致（60–80 s 是 9 好 1 平）。
3. **40–60 s 是唯一负格（10/10 更差，Δ −0.060）**：该窗口参考速度最高（13.05 rad/s），LAB27 反而更早掉出（存活 115 → 54 帧）。→ 「加了同动作的另一段」不是普适增益，会挤占容量（LAB27 的 train MPKPE 5.65 → 7.51 是同一件事）。
4. **增益更像「内容相似」而非「时间相邻」**：对齐误差的增益 0/20/80 s 明显、40/100 s 没有；新颖度与 Δ 的相关强于距离（探索性）。
5. **完成度不能单独用**：它同时被「窗口难度」「存活长度」「reset 时机」污染；跨策略必须用首段对齐误差（本轮 4/6 窗口的「整段 MPKPE 变差」全是假象）。

## 7. 局限

- 只有 1 个训练 seed（LAB25 已证明换 seed 能把 65% 变 23%）。
- 6 个窗口来自同一段 dance1，相邻窗口内容重叠（20 s 步长 vs 1000 帧窗口，不重叠但动作会跨段重复），不独立。
- 首段对齐的 K 只有 28–200 帧（0.6–4 s），样本短；0 s 窗口 K=200 是上限截断。
- 新颖度用 29 维关节位置的一阶统计（无相位/速度对齐），是粗糙的内容代理。
- 只测了 dance1；没有换第二段动作验证「相似度」解释。
